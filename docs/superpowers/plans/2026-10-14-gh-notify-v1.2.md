# gh_notify v1.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make gh_notify installable and self-updating, configurable from a settings window, and quieter or louder exactly where the user wants it. That covers sounds, mute/hide filters, per-item snooze, ready-to-merge and waiting PRs, generic agent workflows, a clearer tray icon, and real docs.

**Architecture:** Pure decision logic lives in `GhNotify.Core` and is unit-tested:
- filters, snoozes and the composed inbox view
- sound planning
- settings draft and validation
- the update state machine

Providers (`GhNotify.GitHub`, `GhNotify.Ado`) gain two PR kinds. `GhNotify.Agents` gains a command runner beside the Claude runner. `GhNotify.App` (WPF) holds the thin UI: popup menus and sections, settings window, tray icon, Velopack entry point and hooks. `build/` scripts and `.github/workflows` carry packaging, install tests and quality gates.

**Tech Stack:** .NET 10, WPF, H.NotifyIcon.Wpf 2.4.1, Microsoft.Toolkit.Uwp.Notifications 7.1.3, Velopack (NuGet `Velopack` + `vpk` dotnet tool, same pinned version), xUnit, Microsoft.Extensions.TimeProvider.Testing, coverlet.collector, GitHub Actions (windows-latest), CodeQL.

**Spec:** `docs/superpowers/specs/2026-10-14-gh-notify-v1.2-design.md` (read it; section numbers below refer to it).

## Global Constraints

- Placeholder names only, everywhere (code, tests, docs, screenshots, examples): orgs and repos `contoso`, `fabrikam`, `acme`; people `alice`, `bob`. Never a real org, client, tenant, subscription or repo name.
- Don't name the employer brand in new files. The theme is "the H theme".
- Config stays at `%APPDATA%\GhNotify\config.json`. App data moves to `%LocalAppData%\GhNotify-data\`. The install root `%LocalAppData%\GhNotify` belongs to Velopack.
- Env overrides: `GHNOTIFY_CONFIG_DIR`, `GHNOTIFY_DATA_DIR`, `GHNOTIFY_UPDATE_FEED`.
- Update source: `https://github.com/JoshHambright/gh_notify`, no token, no prerelease. Check 30 s after launch, then every `updates.checkHours` (default 4, range 1–168). Never restart without the user.
- Builds are unsigned; CI keeps a commented `# SIGNING:` step.
- Built-in sounds: `chime`, `ping`, `alert`, `alarm`, `soft`, generated by `build/make-sounds.ps1` (original, MIT).
- Sound priority: ApprovalPending > MyPrCiFailing > ReviewRequested > MyPrNeedsResponse > MyPrReadyToMerge, then oldest first. At most one played sound per poll.
- MyPrWaiting never toasts, sounds, auto-runs, or counts in the badge or header.
- Command profile result: last 64 KB of stdout+stderr. Summary = first line starting `SUMMARY:`, else the last non-empty line. Exit 0 → Ready, else Failed "exit <code>".
- Command env vars: `GHN_URL, GHN_REPO, GHN_NUMBER, GHN_TITLE, GHN_KIND, GHN_PROVIDER, GHN_AUTHOR, GHN_ITEM_KEY`.
- Settings Save: validate → write `config.json.bak` → atomic write (temp + replace) → reload. Refuse when the file changed on disk since the window opened, unless the user picks Overwrite.
- No modal `MessageBox` in new UI. Confirmations are inline.
- Existing safety stays untouched: agent deny list, two-step approvals, 600 ms confirm guard, pointer guard.
- Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Before building, stop any running app: `Get-Process GhNotify -ErrorAction SilentlyContinue | Stop-Process` (it locks `bin`). Don't relaunch it; the controller does.

## Review Focus

1. **Uninstall must remove the Run key and shortcut and keep `config.json`.** A leftover Run key makes Windows try to start a missing exe at every login. Pinned by `build/test-install.ps1` step 3 (Task 11).
2. **Settings Save racing an external edit of `config.json`** must refuse with a conflict, not silently overwrite. Pinned by `ConfigStoreSaveTests.Save_refuses_when_file_changed_since_hash` (Task 1).
3. **Hiding, muting or snoozing an item, then undoing it, must not re-toast it**, and the item must keep reconciling while hidden. Pinned by `NotificationPlannerTests.Unhide_does_not_retoast` and `InboxViewTests.Hidden_items_still_reported_for_reconcile` (Tasks 3–4).
4. **A command profile whose placeholder (PR title) contains quotes, spaces, `&` or `%`** must stay one argv entry for an .exe. For a .cmd/.bat it must fail the run with a clear message, never run a mangled line. Pinned by `CommandRunnerTests.Title_with_metacharacters_is_one_argument` and `CommandRunnerTests.Cmd_script_with_quote_in_arg_fails_cleanly` (Task 5).
5. **"Restart to update" while agents are running** must ask first, never kill runs silently. Pinned by `UpdateServiceTests.Restart_requires_confirm_when_agents_running` (Task 10).

```csharp
namespace GhNotify.Core;

/// <summary>"[gh:|ado:]seg/seg…" — matches an item whose path starts with these segments; '*' is a within-segment wildcard.</summary>
public sealed class FilterPattern
{
    public string Text { get; }
    public Provider? Provider { get; }
    readonly string[] _segments;

    FilterPattern(string text, Provider? provider, string[] segments)
    {
        Text = text;
        Provider = provider;
        _segments = segments;
    }

    public static bool TryParse(string? text, out FilterPattern? pattern, out string? error)
    {
        pattern = null;
        error = null;
        var body = (text ?? "").Trim();
        Provider? provider = null;
        var colon = body.IndexOf(':');
        if (colon >= 0)
        {
            var prefix = body[..colon].ToLowerInvariant();
            provider = prefix switch { "gh" => Core.Provider.GitHub, "ado" => Core.Provider.Ado, _ => null };
            if (provider is null) { error = $"'{text}': unknown prefix '{prefix}:' (use gh: or ado:)"; return false; }
            body = body[(colon + 1)..];
        }
        if (body.Length == 0) { error = $"'{text}': pattern is empty"; return false; }
        var segments = body.Split('/');
        if (segments.Any(s => s.Length == 0)) { error = $"'{text}': empty segment"; return false; }
        if (segments.Any(s => s.Contains("**"))) { error = $"'{text}': '**' is not supported; use one '*' per segment"; return false; }
        pattern = new FilterPattern(text!.Trim(), provider, segments);
        return true;
    }

    /// <summary>GitHub "org/repo"; ADO "org/project/repo" (approvals: "org/project/pipeline") — the item's Repo field.</summary>
    public static string PathOf(InboxItem item) => item.Repo;

    public bool Matches(InboxItem item)
    {
        if (Provider is { } p && p != item.Provider) return false;
        var path = PathOf(item).Split('/');
        if (_segments.Length > path.Length) return false;
        for (var i = 0; i < _segments.Length; i++)
            if (!ItemMatcher.Glob(_segments[i], path[i])) return false;
        return true;
    }
}
```

```csharp
namespace GhNotify.Core;

public sealed record ConfigError(string Field, string Message);

public static class ConfigValidator
{
    public static IReadOnlyList<ConfigError> Errors(AppConfig c)
    {
        var e = new List<ConfigError>();
        void Add(string field, string message) => e.Add(new ConfigError(field, message));
        bool NotNull(object? v, string field) { if (v is null) { Add(field, $"{field} must not be null"); return false; } return true; }
        bool Entries<T>(List<T>? list, string field)
        {
            if (!NotNull(list, field)) return false;
            var ok = true;
            for (var i = 0; i < list!.Count; i++) ok &= NotNull(list[i], $"{field}[{i}]");
            return ok;
        }

        if (c.PollSeconds < 30) Add("pollSeconds", "pollSeconds must be at least 30");
        if (c.MaxConcurrentAgents < 1) Add("maxConcurrentAgents", "maxConcurrentAgents must be at least 1");
        if (c.AgentTimeoutMinutes < 1) Add("agentTimeoutMinutes", "agentTimeoutMinutes must be at least 1");

        if (NotNull(c.WorkHours, "workHours") && Entries(c.WorkHours.Days, "workHours.days"))
        {
            try { WorkHours.Validate(c.WorkHours); }
            catch (InvalidDataException ex) { Add("workHours", ex.Message); }
        }
        if (NotNull(c.GitHub, "github")) Entries(c.GitHub.WatchRepos, "github.watchRepos");
        if (NotNull(c.Ado, "ado")) { Entries(c.Ado.Orgs, "ado.orgs"); Entries(c.Ado.ExcludeOrgs, "ado.excludeOrgs"); }
        Entries(c.RepoRoots, "repoRoots");
        Entries(c.AgentAllowedTools, "agentAllowedTools");

        if (NotNull(c.Display, "display") && NotNull(c.Display.RepoAliases, "display.repoAliases"))
```

```csharp
    /// <summary>SHA-256 of the file's bytes, or null when it doesn't exist.</summary>
    public string? FileHash()
    {
        if (!File.Exists(Path)) return null;
        return Convert.ToHexString(System.Security.Cryptography.SHA256.HashData(File.ReadAllBytes(Path)));
    }

    public static AppConfig Clone(AppConfig c) =>
        JsonSerializer.Deserialize<AppConfig>(JsonSerializer.Serialize(c, Json.Options), Json.Options)!;

    /// <summary>
    /// Validates, refuses if the file changed since <paramref name="expectedHash"/> (null = overwrite), keeps config.json.bak,
    /// writes atomically and reloads. Throws InvalidDataException (invalid) or ConfigConflictException (changed on disk).
    /// </summary>
    public void Save(AppConfig config, string? expectedHash)
    {
        Validate(config);
        if (expectedHash is not null && FileHash() is { } now && now != expectedHash) throw new ConfigConflictException();
        Directory.CreateDirectory(System.IO.Path.GetDirectoryName(Path)!);
        var tmp = Path + ".tmp";
        File.WriteAllText(tmp, JsonSerializer.Serialize(config, Json.Options));
        if (File.Exists(Path)) File.Replace(tmp, Path, Path + ".bak", ignoreMetadataErrors: true);
        else File.Move(tmp, Path);
        Load();
    }
```

```csharp
/// <summary>v1.2 moved app data out of %LocalAppData%\GhNotify (now the installer's folder). Never throws.</summary>
public static class DataMigration
{
    public static void Run(string legacyDir, string newDir)
    {
        try
        {
            var oldState = Path.Combine(legacyDir, "state.json");
            var newState = Path.Combine(newDir, "state.json");
            if (!File.Exists(oldState) || File.Exists(newState)) return;
            Directory.CreateDirectory(newDir);
            File.Move(oldState, newState);
            var oldLogs = Path.Combine(legacyDir, "logs");
            var newLogs = Path.Combine(newDir, "logs");
            if (Directory.Exists(oldLogs) && !Directory.Exists(newLogs)) Directory.Move(oldLogs, newLogs);
        }
        catch (Exception ex) when (ex is IOException or UnauthorizedAccessException)
        {
            // Best effort: a failed move just means a fresh state file.
        }
    }
}
```

```csharp
    /// <summary>The first start-of-work strictly after <paramref name="fromLocal"/> on a listed day (any day if none listed).</summary>
    public static DateTime NextStart(WorkHoursConfig cfg, DateTime fromLocal)
    {
        var start = Parse(cfg.Start).ToTimeSpan();
        for (var d = 0; d <= 8; d++)
        {
            var candidate = fromLocal.Date.AddDays(d) + start;
            if (candidate > fromLocal && (cfg.Days.Count == 0 || IsDay(cfg, candidate.DayOfWeek))) return candidate;
        }
        return fromLocal.Date.AddDays(1) + start;
    }
```

```csharp
using System.Globalization;

namespace GhNotify.Core;

public enum SnoozeChoice { OneHour, FourHours, Tomorrow, NextWeek, UntilChange }
public enum MuteScope { Repo, Project, Org }
public enum MuteDuration { OneHour, Tomorrow, Forever }

public sealed record SnoozeResult(IReadOnlyList<Snooze> Kept, IReadOnlyList<InboxItem> Woken);

public static class Snoozes
{
    /// <summary>Wakes snoozes whose time passed or whose item changed; drops snoozes for items that left.</summary>
    public static SnoozeResult Evaluate(IReadOnlyList<Snooze> snoozes, InboxDiff diff, IReadOnlyCollection<InboxEntry> present, DateTimeOffset now)
    {
        var byKey = present.GroupBy(e => e.Item.Key).ToDictionary(g => g.Key, g => g.First().Item);
        var changed = diff.Changed.Select(c => c.New.Key).ToHashSet();
        var kept = new List<Snooze>();
        var woken = new List<InboxItem>();
        foreach (var s in snoozes)
        {
            if (!byKey.TryGetValue(s.Key, out var item)) continue;
            if (changed.Contains(s.Key) || s.Until is { } u && u <= now) woken.Add(item);
            else kept.Add(s);
        }
        return new SnoozeResult(kept, woken);
    }

    public static IReadOnlyList<TimedMute> PruneMutes(IReadOnlyList<TimedMute> mutes, DateTimeOffset now) =>
        mutes.Where(m => m.Until is not { } u || u > now).ToList();

    public static string Remaining(Snooze s, DateTimeOffset now) => s.Until is not { } u ? "until it changes" : Left(u - now, u);

    public static string Left(TimeSpan left, DateTimeOffset until) => left switch
    {
        { TotalMinutes: < 1 } => "<1m left",
        { TotalMinutes: < 60 } => $"{(int)left.TotalMinutes}m left",
        { TotalHours: < 48 } => $"{(int)left.TotalHours}h {left.Minutes}m left",
        _ => "until " + until.ToLocalTime().ToString("ddd HH:mm", CultureInfo.InvariantCulture),
    };
}

public static class SnoozeTimes
{
    public static (DateTimeOffset? Until, bool UntilChange) For(SnoozeChoice choice, DateTimeOffset now, WorkHoursConfig wh) => choice switch
    {
        SnoozeChoice.OneHour => (now.AddHours(1), false),
        SnoozeChoice.FourHours => (now.AddHours(4), false),
        SnoozeChoice.Tomorrow => (At(WorkHours.NextStart(wh, now.Date.AddDays(1)), now), false),
        SnoozeChoice.NextWeek => (At(WorkHours.NextStart(wh, NextMonday(now.Date)), now), false),
        _ => (null, true),
    };

    static DateTime NextMonday(DateTime d)
    {
        var days = ((int)DayOfWeek.Monday - (int)d.DayOfWeek + 7) % 7;
        return d.AddDays(days == 0 ? 7 : days).AddTicks(-1); // NextStart is "strictly after", so start just before Monday 00:00
    }

    /// <summary>Interprets a wall-clock time in the same offset as <paramref name="now"/>.</summary>
    internal static DateTimeOffset At(DateTime local, DateTimeOffset now) => new(DateTime.SpecifyKind(local, DateTimeKind.Unspecified), now.Offset);
}

public static class MutePatterns
{
    public static string? For(InboxItem item, MuteScope scope)
    {
        var prefix = item.Provider == Provider.GitHub ? "gh:" : "ado:";
        var seg = item.Repo.Split('/');
        return scope switch
        {
            MuteScope.Repo => prefix + item.Repo,
            MuteScope.Org => prefix + seg[0],
            MuteScope.Project when item.Provider == Provider.Ado && seg.Length >= 2 => $"{prefix}{seg[0]}/{seg[1]}",
            _ => null,
        };
    }

    public static DateTimeOffset? Until(MuteDuration d, DateTimeOffset now, WorkHoursConfig wh) => d switch
    {
        MuteDuration.OneHour => now.AddHours(1),
        MuteDuration.Tomorrow => SnoozeTimes.At(WorkHours.NextStart(wh, now.Date.AddDays(1)), now),
        _ => null,
    };
}
```

```csharp
namespace GhNotify.Core;

public enum Attention { Normal, Muted, Waiting, Snoozed, Hidden }

public sealed record ViewEntry(InboxEntry Entry, Attention Attention, string? MutedBy);
public sealed record SnoozedEntry(InboxEntry Entry, Snooze Snooze);

/// <summary>Classifies reconciled entries for display and alerting. Never removes anything from the reconciler.</summary>
public sealed class InboxView
{
    readonly Dictionary<string, Attention> _attention;
    public IReadOnlyList<ViewEntry> Active { get; }
    public IReadOnlyList<ViewEntry> Waiting { get; }
    public IReadOnlyList<SnoozedEntry> Snoozed { get; }
    public int BadgeCount => Active.Count(e => e.Attention == Attention.Normal);

    InboxView(List<ViewEntry> active, List<ViewEntry> waiting, List<SnoozedEntry> snoozed, Dictionary<string, Attention> attention)
    {
        Active = active;
        Waiting = waiting;
        Snoozed = snoozed;
        _attention = attention;
    }

    public Attention AttentionFor(string key) => _attention.GetValueOrDefault(key, Attention.Normal);

    public static InboxView Compose(IReadOnlyList<InboxEntry> entries, FiltersConfig filters, IReadOnlyList<TimedMute> mutes,
        IReadOnlyList<Snooze> snoozes, DateTimeOffset now)
    {
        var hide = Parse(filters.Hide);
        var mute = Parse(filters.Mute).Concat(Parse(mutes.Where(m => m.Until is not { } u || u > now).Select(m => m.Pattern))).ToList();
        var snoozed = snoozes.GroupBy(s => s.Key).ToDictionary(g => g.Key, g => g.First());
        var active = new List<ViewEntry>();
        var waiting = new List<ViewEntry>();
        var sleeping = new List<SnoozedEntry>();
        var attention = new Dictionary<string, Attention>();
        foreach (var e in entries)
        {
            var item = e.Item;
            Attention a;
            if (hide.Any(p => p.Matches(item))) a = Attention.Hidden;
            else if (snoozed.TryGetValue(item.Key, out var s)) { a = Attention.Snoozed; sleeping.Add(new SnoozedEntry(e, s)); }
            else
            {
                var mutedBy = mute.FirstOrDefault(p => p.Matches(item))?.Text;
                if (item.Kind == ItemKind.MyPrWaiting) { a = Attention.Waiting; waiting.Add(new ViewEntry(e, a, mutedBy)); }
                else { a = mutedBy is null ? Attention.Normal : Attention.Muted; active.Add(new ViewEntry(e, a, mutedBy)); }
            }
            attention[item.Key] = a;
        }
        return new InboxView(active, waiting, sleeping, attention);
    }

    static List<FilterPattern> Parse(IEnumerable<string> patterns) =>
        patterns.Select(t => FilterPattern.TryParse(t, out var p, out _) ? p : null).OfType<FilterPattern>().ToList();
}
```

```csharp
namespace GhNotify.Core;

public sealed record NotificationPlan(IReadOnlyList<ToastRequest> Toasts, string? Sound);

public static class NotificationPlanner
{
    static readonly ItemKind[] Priority =
        [ItemKind.ApprovalPending, ItemKind.MyPrCiFailing, ItemKind.ReviewRequested, ItemKind.MyPrNeedsResponse, ItemKind.MyPrReadyToMerge];

    public static SoundRule? RuleFor(InboxItem item, AppConfig cfg) =>
        cfg.Notifications.Sounds.FirstOrDefault(r => ItemMatcher.Matches(r.Match, item));

    public static NotificationPlan Plan(InboxDiff diff, IReadOnlyList<InboxItem> woken, InboxView view, AppConfig cfg, bool inWorkHours)
    {
        var toasts = new List<ToastRequest>();
        foreach (var r in diff.Removed)
        {
            toasts.Add(new ToastRequest(ToastAction.Remove, ItemTag.For(r.Key)));
            toasts.Add(new ToastRequest(ToastAction.Remove, ItemTag.ForAgent(r.Key)));
        }

        var candidates = diff.Added.Select(i => (Item: i, Back: false)).Concat(woken.Select(i => (Item: i, Back: true)))
            .Where(c => view.AttentionFor(c.Item.Key) == Attention.Normal && c.Item.Kind != ItemKind.MyPrWaiting)
            .Select(c => (c.Item, c.Back, Rule: RuleFor(c.Item, cfg)))
            .Where(c => inWorkHours || c.Rule?.AlertOffHours == true)
            .ToList();

        var winner = candidates.Where(c => (c.Rule?.Sound ?? "default") != "none")
            .OrderBy(c => Array.IndexOf(Priority, c.Item.Kind) is var i && i < 0 ? int.MaxValue : i)
            .ThenBy(c => c.Item.UpdatedAt)
            .Select(c => (c.Item.Key, Sound: c.Rule?.Sound ?? "default"))
            .FirstOrDefault();

        foreach (var c in candidates)
        {
            var carriesDefault = winner.Key == c.Item.Key && winner.Sound == "default";
            toasts.Add(new ToastRequest(ToastAction.Show, ItemTag.For(c.Item.Key),
                (c.Back ? "Back: " : "") + NotificationPolicy.TitleFor(c.Item), $"{c.Item.Repo}: {c.Item.Title}", c.Item.Url)
            { Silent = !carriesDefault });
        }

        if (inWorkHours)
        {
            var initial = diff.InitialLoad.Where(i => view.AttentionFor(i.Key) == Attention.Normal && i.Kind != ItemKind.MyPrWaiting).ToList();
            if (initial.Count > 0)
            {
                var n = initial.Count;
                toasts.Add(new ToastRequest(ToastAction.Show, NotificationPolicy.SummaryTag, $"{n} item{(n == 1 ? "" : "s")} waiting on you",
                    string.Join("\n", initial.Take(3).Select(i => $"{i.Repo}: {i.Title}"))) { Silent = winner.Key is not null });
            }
        }

        var custom = winner.Key is not null && winner.Sound != "default" ? winner.Sound : null;
        return new NotificationPlan(toasts, custom);
    }
}
```

```powershell
    $out = New-Object System.Collections.Generic.List[double]
    foreach ($n in $notes) {
        $f, $sec, $vol = $n; $count = [int]($rate * $sec)

            $env = [Math]::Min(1, $t / 0.005) * [Math]::Exp(-4 * $t / $sec)
            $out.Add($vol * $env * ([Math]::Sin(2 * [Math]::PI * $f * $t) + 0.3 * [Math]::Sin(4 * [Math]::PI * $f * $t)) / 1.3)
        }
    }
    , $out.ToArray()
}
```

```csharp
using System.Collections.Concurrent;
using System.Media;
using System.Windows;
using GhNotify.Core;

namespace GhNotify.App;

public static class SoundPlayerService
{
    static readonly ConcurrentDictionary<string, byte> Warned = new(StringComparer.OrdinalIgnoreCase);

    /// <summary>Plays "builtin:&lt;name&gt;" or a .wav path asynchronously. False (and one log line per path) when it can't.</summary>
    public static bool Play(string sound)
    {
        try
        {
            if (sound.StartsWith("builtin:", StringComparison.OrdinalIgnoreCase))
            {
                var name = sound["builtin:".Length..].ToLowerInvariant();
                if (!SoundNames.BuiltIn.Contains(name)) return false;
                var res = Application.GetResourceStream(new Uri($"pack://application:,,,/GhNotify;component/Sounds/{name}.wav"));
                if (res is null) return false;
                new SoundPlayer(res.Stream).Play();
                return true;
            }
            if (!File.Exists(sound)) throw new FileNotFoundException(sound);
            new SoundPlayer(sound).Play();
            return true;
        }
        catch (Exception ex)
        {
            if (Warned.TryAdd(sound, 0)) Log.Error($"could not play sound '{sound}'", ex);
            return false;
        }
    }

    /// <summary>Plays the sound, falling back to the system notification sound.</summary>
    public static void PlayOrDefault(string sound)
    {
        if (!Play(sound)) SystemSounds.Asterisk.Play();
    }
}
```

```csharp
public interface ICommandRunner

/// <summary>Runs a command profile: argv with placeholders filled per argument (never through a shell), item data in GHN_* env vars.</summary>
public sealed class CommandRunner(IProcessRunner runner) : ICommandRunner
{
    public const int MaxOutput = 64 * 1024;

    public async Task<AgentOutcome> RunAsync(string workingDir, IReadOnlyList<string> command, InboxItem item, TimeSpan timeout, CancellationToken ct)
    {
        var args = command.Skip(1).Select(a => PromptTemplate.Fill(a, item)).ToList();
        try
        {
            var r = await runner.RunAsync(new ProcessSpec(command[0], args, workingDir, null, EnvFor(item), timeout), ct);
            return Parse(r);
        }
        catch (FileNotFoundException)
        {
            return new AgentOutcome(false, null, null, null, $"'{command[0]}' not found");
        }
        catch (ArgumentException ex)
        {
            return new AgentOutcome(false, null, null, null, ex.Message);
        }
    }

    public static IReadOnlyDictionary<string, string> EnvFor(InboxItem i) => new Dictionary<string, string>
    {
        ["GHN_URL"] = i.Url,
        ["GHN_REPO"] = i.Repo,
        ["GHN_NUMBER"] = i.Number?.ToString() ?? "",
        ["GHN_TITLE"] = i.Title,
        ["GHN_KIND"] = i.Kind.ToString(),
        ["GHN_PROVIDER"] = i.Provider.ToString(),
        ["GHN_AUTHOR"] = i.Author,
        ["GHN_ITEM_KEY"] = i.Key,
    };

    public static AgentOutcome Parse(ProcessResult r)
    {
        var text = r.StdErr.Length == 0 ? r.StdOut : r.StdOut + "\n" + r.StdErr;
        if (text.Length > MaxOutput) text = text[^MaxOutput..];
        if (r.TimedOut) return new AgentOutcome(false, null, null, null, "timed out") { ResultText = text };
        var lines = text.Split('\n').Select(l => l.Trim()).Where(l => l.Length > 0).ToList();
        var summaryLine = lines.FirstOrDefault(l => l.StartsWith("SUMMARY:", StringComparison.OrdinalIgnoreCase));
        var summary = summaryLine is not null ? summaryLine["SUMMARY:".Length..].Trim() : lines.LastOrDefault();
        if (summary is { Length: > 200 }) summary = summary[..200] + "…";
        var ok = r.ExitCode == 0;
        return new AgentOutcome(ok, null, summary, null, ok ? null : $"exit {r.ExitCode}") { ResultText = text };
    }
```

```csharp
using System.Text.Json;

namespace GhNotify.Core;

public enum SettingsPage { General, Sources, Notifications, Filters, Workflows, Advanced }

public sealed record SettingsError(SettingsPage Page, string Field, string Message);

/// <summary>An editable deep copy of the config for the settings window; nothing here touches disk.</summary>
public sealed class SettingsDraft
{
    readonly string _original;

    public SettingsDraft(AppConfig current, string? fileHash)
    {
        Config = ConfigStore.Clone(current);
        _original = Serialize(Config);
        FileHashAtOpen = fileHash;
    }

    public AppConfig Config { get; private set; }
    public string? FileHashAtOpen { get; }
    public bool IsDirty => Serialize(Config) != _original;

    public IReadOnlyList<SettingsError> Validate() =>
        ConfigValidator.Errors(Config).Select(e => new SettingsError(PageFor(e.Field), e.Field, e.Message)).ToList();

    public void ResetToDefaults()
    {
        var extra = Config.Extra;
        Config = new AppConfig { Extra = extra };
    }

    static string Serialize(AppConfig c) => JsonSerializer.Serialize(c, Json.Options);

    public static SettingsPage PageFor(string field)
    {
        var head = field.Split('.', '[')[0];
        return head switch
        {
            "pollSeconds" or "workHours" or "updates" or "maxConcurrentAgents" or "agentTimeoutMinutes" => SettingsPage.General,
            "github" or "ado" or "repoRoots" or "display" => SettingsPage.Sources,
            "notifications" => SettingsPage.Notifications,
            "filters" => SettingsPage.Filters,
            "rules" or "agentProfiles" or "defaultProfiles" or "hooks" or "agentAllowedTools" => SettingsPage.Workflows,
            _ => SettingsPage.Advanced,
        };
    }

    public static bool Move<T>(List<T> list, int index, int delta)
    {
        var to = index + delta;
        if (index < 0 || index >= list.Count || to < 0 || to >= list.Count) return false;
        (list[index], list[to]) = (list[to], list[index]);
        return true;
    }

    public static string KindLabel(ItemKind? kind) => kind switch
    {
        null => "Any item",
        ItemKind.ReviewRequested => "Review requested",
        ItemKind.ApprovalPending => "Approval pending",
        ItemKind.MyPrCiFailing => "My PR — CI failing",
        ItemKind.MyPrNeedsResponse => "My PR — needs response",
        ItemKind.MyPrReadyToMerge => "My PR — ready to merge",
        ItemKind.MyPrWaiting => "My PR — waiting on others",
        _ => kind.ToString()!,
    };

    public static string SoundLabel(string sound) => sound switch
    {
        "default" => "Windows default",
        "none" => "None",
        _ when sound.StartsWith("builtin:", StringComparison.OrdinalIgnoreCase) =>
            char.ToUpperInvariant(sound["builtin:".Length]) + sound["builtin:".Length..][1..],
        _ => Path.GetFileName(sound),
    };

    static string Where(ItemMatch? m)
    {
        var s = $"When {KindLabel(m?.Kind)} in {(string.IsNullOrEmpty(m?.Repo) ? "any repo" : m!.Repo)}";
        if (!string.IsNullOrEmpty(m?.Author)) s += $" by {m!.Author}";
        if (m?.MaxChangedLines is { } n) s += $" ≤ {n} lines";
        return s;
    }

    public static string Summary(Rule r)
    {
        var profile = r.Profile ?? (r.Match?.Kind is { } k ? RulesEngine.DefaultProfileFor(k, new AppConfig()) : null);
        var mode = r.Agent switch { AgentMode.Auto => "Auto", AgentMode.None => "Off", _ => "Button" };
        return $"{Where(r.Match)} → {(profile is null ? "default" : InboxPresenter.LabelFor(profile))} · {mode}";
    }

    public static string Summary(SoundRule s) =>
        $"{Where(s.Match)} → {SoundLabel(s.Sound)}" + (s.AlertOffHours ? " · alert off-hours" : "");

    public static int CountMatches(string pattern, IEnumerable<InboxItem> items) =>
        FilterPattern.TryParse(pattern, out var p, out _) ? items.Count(p!.Matches) : -1;

    /// <summary>True when the JSON text has // or /* comments outside string literals.</summary>
    public static bool HasComments(string json)
    {
        var inString = false;
        for (var i = 0; i < json.Length; i++)
        {
            var c = json[i];
            if (inString)
            {
                if (c == '\\') i++;
                else if (c == '"') inString = false;
            }
            else if (c == '"') inString = true;
            else if (c == '/' && i + 1 < json.Length && json[i + 1] is '/' or '*') return true;
        }
        return false;
    }
}
```

```csharp
public sealed class UpdateService(IUpdateClient client, Func<UpdatesConfig> config, TimeProvider? time = null)
{
    readonly TimeProvider _time = time ?? TimeProvider.System;
    readonly SemaphoreSlim _gate = new(1, 1);
    UpdateCandidate? _ready;

    public UpdateStatus Status { get; private set; } = new(client.IsInstalled ? UpdatePhase.Idle : UpdatePhase.DevBuild, client.CurrentVersion, null, null, null);
    public event Action? Changed;

    void Set(UpdateStatus s) { Status = s; Changed?.Invoke(); }

    public async Task CheckNowAsync(CancellationToken ct)
    {
        if (!client.IsInstalled) { Set(Status with { Phase = UpdatePhase.DevBuild }); return; }
        if (!config().Enabled) { Set(Status with { Phase = UpdatePhase.Off }); return; }
        if (_ready is not null) return; // already downloaded; waiting for the user to restart
        if (!await _gate.WaitAsync(0, ct)) return;
        try
        {
            Set(Status with { Phase = UpdatePhase.Checking, LastError = null });
            var next = await client.CheckAsync(ct);
            if (next is null) { Set(Status with { Phase = UpdatePhase.Idle, LastChecked = _time.GetUtcNow() }); return; }
            Set(Status with { Phase = UpdatePhase.Downloading });
            await client.DownloadAsync(next, ct);
            _ready = next;
            Set(Status with { Phase = UpdatePhase.Ready, ReadyVersion = next.Version, LastChecked = _time.GetUtcNow() });
        }
        catch (OperationCanceledException) when (ct.IsCancellationRequested) { }
        catch (Exception ex)
        {
            Log.Error("update check failed", ex);
            Set(Status with { Phase = UpdatePhase.Failed, LastError = ex.Message, LastChecked = _time.GetUtcNow() });
        }
        finally { _gate.Release(); }
    }

    public async Task RunAsync(CancellationToken ct)
    {
        try
        {
            await Task.Delay(TimeSpan.FromSeconds(30), _time, ct);
            while (!ct.IsCancellationRequested)
            {
                await CheckNowAsync(ct);
                await Task.Delay(TimeSpan.FromHours(Math.Clamp(config().CheckHours, 1, 168)), _time, ct);
            }
        }
        catch (OperationCanceledException) { }
    }

    public RestartDecision RequestRestart(int runningAgents, bool confirmed)
    {
        if (_ready is null) return RestartDecision.NothingToApply;
        if (runningAgents > 0 && !confirmed) return RestartDecision.NeedsConfirm;
        client.ApplyOnExit(_ready);
        return RestartDecision.Restarting;
    }
}
```

```csharp
public static class InstallInfo

    /// <summary>The exe path that survives updates when running from a Velopack install; null for dev builds.</summary>
    public static string? StablePathFor(string processPath)
```
