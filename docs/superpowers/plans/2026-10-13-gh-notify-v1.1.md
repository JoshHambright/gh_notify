# gh_notify v1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle gh_notify in the Emergent template look (H popup, B1 icon, dark and light themes). Add two-step in-app approvals for deployments, pipelines and PRs, and expandable row details with the full agent result.

**Architecture:**
- **Core** gets the new item fields, the action contracts and text, theme resolution, badge text, and a presenter that emits expand/confirm row state.
- **GitHub/ADO** fill in the new fields and details, and each gets an `IItemActions` that runs fresh checks and sends writes through its existing authenticated client.
- **App** gets theme dictionaries, bundled Roboto, a code-drawn tray icon, a `--render-preview` mode, and the restyled popup.

**Tech Stack:** .NET 10, WPF, H.NotifyIcon.Wpf, Microsoft.Toolkit.Uwp.Notifications, xUnit, FakeTimeProvider.

**Spec:** `docs/superpowers/specs/2026-10-13-gh-notify-v1.1-design.md` (and v1 `2026-10-13-gh-notify-design.md`). Read the v1.1 spec before any task.

## Global Constraints

- All v1 Global Constraints still apply (see `docs/superpowers/plans/2026-10-13-gh-notify.md`).
- Colours, exactly as in spec §2:
  - Dark: surface `#000C1A`, raised `#0B1A29`, text `#FFFFFF`, muted `#8296AB`, section `#9FB0C2`, hairline `#0F2236`
  - Light: surface `#FFFFFF`, raised `#EBF0F5`, text `#000C1A`, muted `#5D7186`, section `#223648`, hairline `#D8E1EB`
  - Both themes: red `#ED352F`, amber `#F9B700`, green `#37B84D` (ready text `#5FD474` dark / `#238A36` light), blue `#0072DA`
- Fonts: Roboto Black for the title and count, Roboto Regular/Medium/Bold elsewhere, Segoe UI fallback.
- Every write action is two-step: the first click previews, and only the second click (on a button naming the target) sends. The confirm button is disabled for 600 ms after the panel opens.
- Every action runs a fresh live check immediately before sending (spec §4.2) and refuses on any mismatch.
- Agents never trigger actions, and the agent deny list is unchanged.
- No action buttons on MyPrCiFailing or MyPrNeedsResponse items.
- `AgentRun.ResultText` is capped at 32 768 characters.
- Logs record the action, the item key, the outcome and the comment length, never the comment text or tokens.

## Review Focus

1. **A double click on the action button must not approve.** The second step's button only enables after 600 ms. Pinned in Task 7 (presenter/UI state) and Task 3.
2. **A PR with new commits after the preview is shown must be refused**, not approved at the new head. Pinned in Tasks 4 and 5 (head-SHA mismatch tests).
3. **GitHub approval where some environments are no longer approvable.** Only the still-approvable environment ids are sent, and the statement names those. Pinned in Task 4.
4. **A Reject comment containing quotes or newlines** must be JSON-encoded, not string-built. Pinned in Tasks 4 and 5 (body asserted via parsed JSON).
5. **Theme = System while Windows switches light/dark.** The popup re-themes live without a restart. Pinned in Task 6 (ThemeService raises a change event; manual check in preview).

```csharp
using System.Net;

namespace GhNotify.Core;

public enum ItemAction { Approve, Reject, ApprovePr }

/// <summary>Result of the fresh live check; Token carries provider data from preview to execute (e.g. environment ids, commit sha).</summary>
public sealed record ActionPreview(bool Allowed, string Statement, string ConfirmLabel, string? Warning, string? RefusalReason, object? Token);

public sealed record ActionResult(bool Ok, string? Error, bool Stale = false);

public interface IItemActions
{
    IReadOnlyList<ItemAction> ActionsFor(InboxItem item);
    Task<ActionPreview> PreviewAsync(InboxItem item, ItemAction action, AgentRun? run, CancellationToken ct);
    Task<ActionResult> ExecuteAsync(InboxItem item, ItemAction action, ActionPreview preview, string? comment, CancellationToken ct);
}

public sealed class CompositeItemActions(IReadOnlyDictionary<Provider, IItemActions> byProvider) : IItemActions
{
    public IReadOnlyList<ItemAction> ActionsFor(InboxItem item) =>
        byProvider.TryGetValue(item.Provider, out var a) ? a.ActionsFor(item) : [];

    public Task<ActionPreview> PreviewAsync(InboxItem item, ItemAction action, AgentRun? run, CancellationToken ct) =>
        byProvider.TryGetValue(item.Provider, out var a)
            ? a.PreviewAsync(item, action, run, ct)
            : Task.FromResult(ActionText.Refuse("Not supported for this source"));

    public Task<ActionResult> ExecuteAsync(InboxItem item, ItemAction action, ActionPreview preview, string? comment, CancellationToken ct) =>
        byProvider.TryGetValue(item.Provider, out var a)
            ? a.ExecuteAsync(item, action, preview, comment, ct)
            : Task.FromResult(new ActionResult(false, "Not supported for this source"));
}

public static class ActionText
{
    public const string NoPreReview = "No pre-review at this commit.";

    public static IReadOnlyList<ItemAction> DefaultActions(InboxItem item) => item.Kind switch
    {
        ItemKind.ApprovalPending => [ItemAction.Approve, ItemAction.Reject],
        ItemKind.ReviewRequested => [ItemAction.ApprovePr],
        _ => [],
    };

    public static string ButtonLabel(ItemAction a) => a switch
    {
        ItemAction.Approve => "Approve…",
        ItemAction.Reject => "Reject…",
        _ => "Approve PR…",
    };

    public static string? PrWarning(InboxItem item, AgentRun? run) =>
        run is { State: AgentState.Ready } r && r.HeadSha == item.HeadSha ? null : NoPreReview;

    public static ActionResult FromHttpError(HttpRequestException ex) => ex.StatusCode switch
    {
        HttpStatusCode.Unauthorized or HttpStatusCode.Forbidden =>
            new(false, "You don't have permission to approve this" + (ex.Message.Length is > 0 and < 160 ? $": {ex.Message}" : "")),
        HttpStatusCode.NotFound or HttpStatusCode.Conflict or HttpStatusCode.UnprocessableEntity =>
            new(false, "This changed since you looked — refreshing", Stale: true),
        _ => new(false, ex.Message),
    };

    public static ActionPreview Refuse(string reason) => new(false, "", "", null, reason, null);
}
```

```csharp
namespace GhNotify.Core;

public static class DetailList
{
    /// <summary>Builds an ordered detail list, skipping null/blank values.</summary>
    public static IReadOnlyList<ItemDetail> Of(params (string Label, string? Value)[] entries) =>
        entries.Where(e => !string.IsNullOrWhiteSpace(e.Value)).Select(e => new ItemDetail(e.Label, e.Value!)).ToList();

    public static string? Short(string? sha) => sha is { Length: > 7 } ? sha[..7] : sha;

    public static string? Local(DateTimeOffset d) => d == DateTimeOffset.MinValue ? null : d.ToLocalTime().ToString("yyyy-MM-dd HH:mm");

    public static string StripHeads(string? refName) =>
        refName is not null && refName.StartsWith("refs/heads/", StringComparison.Ordinal) ? refName["refs/heads/".Length..] : refName ?? "";
}
```
