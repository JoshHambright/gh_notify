# gh_notify Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Windows tray app that shows a live "waiting on me" inbox for
GitHub and Azure DevOps. It toasts new items during work hours and clears
resolved ones. It can also pre-run Claude agents (`/peer-review`,
`/pr-shepherd`, or custom profiles) and fire user hooks.

**Architecture:** A .NET 10 solution with these projects:

- `GhNotify.Core`: models, config, reconciler, rules, poller, hooks and presenter. It has no I/O beyond files and processes.
- `GhNotify.GitHub` and `GhNotify.Ado`: `IInboxSource` providers that talk to REST/GraphQL with tokens borrowed from the `gh` and `az` CLIs.
- `GhNotify.Agents`: finds clones, creates throwaway worktrees, runs and resumes `claude`.
- `GhNotify.App`: a thin WPF tray shell over all of the above.

Every poll reconciles against live state. An unhealthy source never removes items.

**Tech Stack:** .NET 10 SDK (10.0.400), C# latest, WPF, `H.NotifyIcon.Wpf`,
`Microsoft.Toolkit.Uwp.Notifications`, xUnit, `Microsoft.Extensions.TimeProvider.Testing`.

**Spec:** `docs/superpowers/specs/2026-10-13-gh-notify-design.md`. Read it before starting any task.

## Global Constraints

- Target `net10.0` for libraries and tests, and `net10.0-windows10.0.19041.0` for `GhNotify.App`.
- The only runtime NuGet dependencies are `H.NotifyIcon.Wpf` and `Microsoft.Toolkit.Uwp.Notifications` (App only). Tests may also use `xunit`, `xunit.runner.visualstudio`, `Microsoft.NET.Test.Sdk` and `Microsoft.Extensions.TimeProvider.Testing`.
- Auth comes only from `gh auth token` and `az account get-access-token --resource 499b84ac-1321-427f-aa17-267ca6975798`. Tokens are never written to disk or logs.
- Unattended agents must never post, comment, vote, merge, commit or push. The global deny list (`AgentSafety.DisallowedTools`) is always applied.
- Paths:
  - Config: `%APPDATA%\GhNotify\config.json`
  - State: `%LOCALAPPDATA%\GhNotify\state.json`
  - Logs: `%LOCALAPPDATA%\GhNotify\logs\` (7-day retention)
  - Worktrees: `%LOCALAPPDATA%\GhNotify\worktrees\<tag>`
  - Scratch: `%LOCALAPPDATA%\GhNotify\scratch\<tag>`
- Defaults:
  - `pollSeconds` 120 (minimum 30); per-source timeout 30 s
  - `maxConcurrentAgents` 2; `agentTimeoutMinutes` 20
  - Work hours Mon–Fri 08:00–18:00
  - Hook timeout 60 s
  - Project list cache 1 h; group membership cache 24 h; ADO org discovery refresh 1 h
- Toast tag = the first 16 lowercase hex characters of SHA-256(UTF-8 key).
- An unhealthy or absent source never causes item removals. Only `RetireWhere` (config disabled or excluded) removes a source's items.
- Item keys:
  - `gh:review:{owner/repo}#{n}`, `gh:cifail:…`, `gh:respond:…`
  - `gh:approval:{owner/repo}/runs/{runId}`
  - `ado:review:{org}/{project}/{repo}#{id}`, `ado:cifail:…`, `ado:respond:…`
  - `ado:approval:{org}/{project}/{approvalId}`
- Namespaces match the project names (`GhNotify.Core`, `GhNotify.GitHub`, `GhNotify.Ado`, `GhNotify.Agents`, `GhNotify.App`). Use file-scoped namespaces, nullable enabled and implicit usings.

## Review Focus

1. **Bot authors.** GitHub GraphQL reports Dependabot's login as `dependabot`, while users write rules for `dependabot[bot]`. A rule `{"author":"dependabot[bot]"}` must match. Pinned in Task 5 (mapper appends `[bot]` when `__typename == "Bot"`).
2. **PR titles containing `{url}` or other placeholder text.** Prompt filling must be single-pass, so a title is never re-substituted. Pinned in Task 2.
3. **Restarting with `az` logged out.** The ADO items from the last session must stay visible as stale, not vanish. Pinned in Task 3 (an absent source is kept) and Task 7 (the catalog returns `FailedSource("ADO")` and keeps the last discovered orgs).
4. **A review request removed and then re-requested after a push.** The agent run's `ItemRemovedAt` must be cleared, it must go Outdated if the head changed, and the sweep must not delete its worktree. Pinned in Task 12.
5. **An agent writing `**SUMMARY:** …` in markdown.** The summary must still be extracted, without the asterisks. Pinned in Task 12.

```csharp
using System.Globalization;
using System.Text.Json;

namespace GhNotify.Core;

/// <summary>Null-tolerant accessors: missing or wrong-typed properties yield null/default instead of throwing.</summary>
public static class JsonExt
{
    static bool TryGet(JsonElement e, string name, out JsonElement v)
    {
        v = default;
        return e.ValueKind == JsonValueKind.Object && e.TryGetProperty(name, out v);
    }

    public static string? Str(this JsonElement e, string name) =>
        TryGet(e, name, out var v) && v.ValueKind == JsonValueKind.String ? v.GetString() : null;

    public static int? Int(this JsonElement e, string name) =>
        TryGet(e, name, out var v) && v.ValueKind == JsonValueKind.Number && v.TryGetInt32(out var i) ? i : null;

    public static long? Long(this JsonElement e, string name) =>
        TryGet(e, name, out var v) && v.ValueKind == JsonValueKind.Number && v.TryGetInt64(out var i) ? i : null;

    public static bool Bool(this JsonElement e, string name) =>
        TryGet(e, name, out var v) && v.ValueKind == JsonValueKind.True;

    public static JsonElement Obj(this JsonElement e, string name) =>
        TryGet(e, name, out var v) && v.ValueKind == JsonValueKind.Object ? v : default;

    public static IEnumerable<JsonElement> Arr(this JsonElement e, string name) =>
        TryGet(e, name, out var v) && v.ValueKind == JsonValueKind.Array ? v.EnumerateArray() : [];

    public static DateTimeOffset Date(this JsonElement e, string name) =>
        DateTimeOffset.TryParse(e.Str(name), CultureInfo.InvariantCulture, DateTimeStyles.AssumeUniversal, out var d)
            ? d : DateTimeOffset.MinValue;
}
```

```csharp
namespace GhNotify.Core;

public static class Log
{
    static readonly object Gate = new();
    static string? _dir;

    public static void Configure(string dir)
    {
        Directory.CreateDirectory(dir);
        _dir = dir;
        foreach (var f in Directory.GetFiles(dir, "*.log"))
            if (File.GetLastWriteTimeUtc(f) < DateTime.UtcNow.AddDays(-7))
                try { File.Delete(f); } catch (IOException) { }
    }

    public static void Info(string message) => Write("INFO", message);

    public static void Error(string message, Exception? ex = null) =>
        Write("ERROR", ex is null ? message : $"{message}: {ex}");

    static void Write(string level, string message)
    {
        if (_dir is null) return;
        lock (Gate)
        {
            try
            {
                File.AppendAllText(Path.Combine(_dir, $"{DateTime.Now:yyyy-MM-dd}.log"),
                    $"{DateTime.Now:HH:mm:ss} {level} {message}{Environment.NewLine}");
            }
            catch (IOException) { }
        }
    }
}
```

```csharp
using System.Diagnostics;

namespace GhNotify.Core;

/// <summary>Resolves a command on PATH (.exe/.cmd/.bat) and builds a ProcessStartInfo; .cmd/.bat run via cmd.exe.</summary>
public static class CommandResolver
{
    public static string? Find(string name)
    {
        if (Path.IsPathRooted(name)) return File.Exists(name) ? name : null;
        string[] exts = Path.HasExtension(name) ? [""] : [".exe", ".cmd", ".bat"];
        var dirs = (Environment.GetEnvironmentVariable("PATH") ?? "")
            .Split(';', StringSplitOptions.RemoveEmptyEntries | StringSplitOptions.TrimEntries);
        foreach (var dir in dirs)
            foreach (var ext in exts)
            {
                var candidate = Path.Combine(dir.Trim('"'), name + ext);
                if (File.Exists(candidate)) return candidate;
            }
        return null;
    }

    public static ProcessStartInfo CreateStartInfo(string name, IReadOnlyList<string> args)
    {
        var path = Find(name) ?? throw new FileNotFoundException($"'{name}' was not found on PATH", name);
        var ext = Path.GetExtension(path);
        if (ext.Equals(".cmd", StringComparison.OrdinalIgnoreCase) || ext.Equals(".bat", StringComparison.OrdinalIgnoreCase))
        {
            // cmd /s /c "<whole line>": /s strips only the outer quotes, so quoted paths and args survive.
            var line = string.Join(' ', new[] { path }.Concat(args).Select(Quote));
            return new ProcessStartInfo("cmd.exe") { Arguments = $"/d /s /c \"{line}\"" };
        }
        var psi = new ProcessStartInfo(path);
        foreach (var a in args) psi.ArgumentList.Add(a);
        return psi;
    }

    static string Quote(string s) =>
        s.Length > 0 && s.IndexOfAny([' ', '\t', '"', '&', '|', '<', '>', '^']) < 0 ? s : "\"" + s.Replace("\"", "\\\"") + "\"";
}
```

```csharp
using System.Diagnostics;
using System.Text;

namespace GhNotify.Core;

public sealed class ProcessRunner : IProcessRunner
{
    static readonly Encoding Utf8 = new UTF8Encoding(false);

    public async Task<ProcessResult> RunAsync(ProcessSpec spec, CancellationToken ct = default)
    {
        var psi = CommandResolver.CreateStartInfo(spec.FileName, spec.Args);
        psi.UseShellExecute = false;
        psi.CreateNoWindow = true;
        psi.RedirectStandardOutput = true;
        psi.RedirectStandardError = true;
        psi.RedirectStandardInput = spec.StdIn is not null;
        psi.StandardOutputEncoding = Utf8;
        psi.StandardErrorEncoding = Utf8;
        if (spec.StdIn is not null) psi.StandardInputEncoding = Utf8;
        if (spec.WorkingDirectory is not null) psi.WorkingDirectory = spec.WorkingDirectory;
        if (spec.Env is not null)
            foreach (var (k, v) in spec.Env) psi.Environment[k] = v;

        using var p = Process.Start(psi) ?? throw new InvalidOperationException($"failed to start {spec.FileName}");
        var stdout = p.StandardOutput.ReadToEndAsync(CancellationToken.None);
        var stderr = p.StandardError.ReadToEndAsync(CancellationToken.None);
        if (spec.StdIn is not null)
        {
            try
            {
                await p.StandardInput.WriteAsync(spec.StdIn);
                p.StandardInput.Close();
            }
            catch (IOException) { /* process exited without reading stdin */ }
        }

        using var cts = CancellationTokenSource.CreateLinkedTokenSource(ct);
        if (spec.Timeout is { } t) cts.CancelAfter(t);
        var timedOut = false;
        try
        {
            await p.WaitForExitAsync(cts.Token);
        }
        catch (OperationCanceledException)
        {
            try { p.Kill(entireProcessTree: true); } catch (InvalidOperationException) { }
            await p.WaitForExitAsync(CancellationToken.None);
            if (ct.IsCancellationRequested) throw;
            timedOut = true;
        }
        return new ProcessResult(timedOut ? -1 : p.ExitCode, await stdout, await stderr, timedOut);
    }

    public void StartDetached(ProcessSpec spec)
    {
        var psi = CommandResolver.CreateStartInfo(spec.FileName, spec.Args);
        psi.UseShellExecute = false;
        psi.CreateNoWindow = false;
        if (spec.WorkingDirectory is not null) psi.WorkingDirectory = spec.WorkingDirectory;
        Process.Start(psi)?.Dispose();
    }
```

```csharp
using System.Text.Json;

namespace GhNotify.Core;

/// <summary>Loads config.json; on any error keeps the last good config and exposes the error.</summary>
public sealed class ConfigStore(string path)
{
    public string Path { get; } = path;
    public AppConfig Current { get; private set; } = new();
    public string? Error { get; private set; }

    public void Load()
    {
        try
        {
            if (!File.Exists(Path))
            {
                Directory.CreateDirectory(System.IO.Path.GetDirectoryName(Path)!);
                File.WriteAllText(Path, JsonSerializer.Serialize(new AppConfig(), Json.Options));
                Current = new AppConfig();
                Error = null;
                return;
            }
            var config = JsonSerializer.Deserialize<AppConfig>(File.ReadAllText(Path), Json.Options)
                         ?? throw new InvalidDataException("config.json is empty");
            Validate(config);
            Current = config;
            Error = null;
        }
        catch (Exception ex) when (ex is JsonException or InvalidDataException or IOException or UnauthorizedAccessException)
        {
            Error = $"config.json: {ex.Message}";
            Log.Error(Error);
        }
    }

    public static void Validate(AppConfig c)
    {
        if (c.PollSeconds < 30) throw new InvalidDataException("pollSeconds must be at least 30");
        if (c.MaxConcurrentAgents < 1) throw new InvalidDataException("maxConcurrentAgents must be at least 1");
        if (c.AgentTimeoutMinutes < 1) throw new InvalidDataException("agentTimeoutMinutes must be at least 1");
        for (var i = 0; i < c.Hooks.Count; i++)
            if (c.Hooks[i].Run.Count == 0 || string.IsNullOrWhiteSpace(c.Hooks[i].Run[0]))
                throw new InvalidDataException($"hooks[{i}].run must name a command");
    }
}
```

```csharp
using System.Globalization;

namespace GhNotify.Core;

public static class WorkHours
{
    public static bool IsWithin(WorkHoursConfig cfg, DateTime local)
    {
        var start = Parse(cfg.Start);
        var end = Parse(cfg.End);
        var t = TimeOnly.FromDateTime(local);
        if (start == end) return IsDay(cfg, local.DayOfWeek);
        if (start < end) return IsDay(cfg, local.DayOfWeek) && t >= start && t < end;
        // Overnight: opens on a listed day at start, closes the next morning at end.
        return (t >= start && IsDay(cfg, local.DayOfWeek)) || (t < end && IsDay(cfg, local.AddDays(-1).DayOfWeek));
    }

    public static void Validate(WorkHoursConfig cfg)
    {
        Parse(cfg.Start);
        Parse(cfg.End);
        foreach (var d in cfg.Days)
            if (ToDay(d) is null) throw new InvalidDataException($"workHours.days: unknown day '{d}'");
    }

    static TimeOnly Parse(string s) =>
        TimeOnly.TryParseExact(s, "HH:mm", CultureInfo.InvariantCulture, DateTimeStyles.None, out var t)
            ? t : throw new InvalidDataException($"workHours: '{s}' is not HH:mm");

    static bool IsDay(WorkHoursConfig cfg, DayOfWeek day) => cfg.Days.Any(d => ToDay(d) == day);

    static DayOfWeek? ToDay(string s)
    {
        if (s.Length < 3) return null;
        foreach (var d in Enum.GetValues<DayOfWeek>())
            if (d.ToString().StartsWith(s, StringComparison.OrdinalIgnoreCase)) return d;
        return null;
```

Semantics (from spec §4):
- A source seen for the first time (not in the snapshot) puts its items in `InitialLoad`, not `Added`.
- An unhealthy result keeps the source's last items. They are marked `Stale` and nothing is removed.
- A source absent from `results` is treated like an unhealthy one, with Problem "not polled".
- `Changed` fires only when `HeadSha`, `Detail` or `Title` differ. Other field changes (for example `UpdatedAt`) replace the stored item silently.
- `RetireWhere` drops matching sources and reports their items as `Removed`.

```csharp
namespace GhNotify.Core;

public sealed record ItemChange(InboxItem Old, InboxItem New)
{
    public bool HeadChanged => !string.Equals(Old.HeadSha, New.HeadSha, StringComparison.Ordinal);
}

public sealed record InboxDiff(
    IReadOnlyList<InboxItem> Added,
    IReadOnlyList<InboxItem> Removed,
    IReadOnlyList<ItemChange> Changed,
    IReadOnlyList<InboxItem> InitialLoad)
{
    public static readonly InboxDiff Empty = new([], [], [], []);
    public bool IsEmpty => Added.Count == 0 && Removed.Count == 0 && Changed.Count == 0 && InitialLoad.Count == 0;
}

public sealed record SourceStatus(string Name, bool Healthy, string? Problem, DateTimeOffset? LastSuccess);

public sealed record InboxEntry(InboxItem Item, string Source, bool Stale);

public sealed class Reconciler
{
    readonly object _gate = new();
    readonly Dictionary<string, Dictionary<string, InboxItem>> _bySource = new();
    readonly Dictionary<string, SourceStatus> _status = new();

    public Reconciler(IReadOnlyDictionary<string, IReadOnlyList<InboxItem>>? snapshot = null)
    {
        if (snapshot is null) return;
        foreach (var (name, items) in snapshot)
        {
            _bySource[name] = Index(items);
            _status[name] = new SourceStatus(name, true, null, null);
        }
    }

    public InboxDiff Apply(IReadOnlyDictionary<string, SourceResult> results, DateTimeOffset now)
    {
        lock (_gate)
        {
            List<InboxItem> added = [], removed = [], initial = [];
            List<ItemChange> changed = [];
            foreach (var (name, result) in results)
            {
                if (!result.Healthy)
                {
                    _status[name] = new SourceStatus(name, false, result.Problem, _status.GetValueOrDefault(name)?.LastSuccess);
                    continue;
                }
                var fresh = Index(result.Items);
                if (!_bySource.TryGetValue(name, out var old))
                {
                    initial.AddRange(fresh.Values);
                }
                else
                {
                    foreach (var item in fresh.Values)
                    {
                        if (!old.TryGetValue(item.Key, out var prev)) added.Add(item);
                        else if (prev.HeadSha != item.HeadSha || prev.Detail != item.Detail || prev.Title != item.Title)
                            changed.Add(new ItemChange(prev, item));
                    }
                    removed.AddRange(old.Values.Where(o => !fresh.ContainsKey(o.Key)));
                }
                _bySource[name] = fresh;
                _status[name] = new SourceStatus(name, true, null, now);
            }
            foreach (var name in _status.Keys.Where(n => !results.ContainsKey(n)).ToList())
                _status[name] = _status[name] with { Healthy = false, Problem = "not polled" };
            return new InboxDiff(added, removed, changed, initial);
        }
    }

    public InboxDiff RetireWhere(Func<string, bool> sourcePredicate)
    {
        lock (_gate)
        {
            var removed = new List<InboxItem>();
            foreach (var name in _status.Keys.Where(sourcePredicate).ToList())
            {
                if (_bySource.Remove(name, out var items)) removed.AddRange(items.Values);
                _status.Remove(name);
            }
            return removed.Count == 0 ? InboxDiff.Empty : new InboxDiff([], removed, [], []);
        }
    }

    public IReadOnlyList<InboxEntry> Entries
    {
        get
        {
            lock (_gate)
                return _bySource
                    .SelectMany(s => s.Value.Values.Select(i => new InboxEntry(i, s.Key, !_status[s.Key].Healthy)))
                    .OrderByDescending(e => e.Item.UpdatedAt)
                    .ToList();
        }
    }

    public IReadOnlyList<SourceStatus> Statuses
    {
        get { lock (_gate) return _status.Values.OrderBy(s => s.Name).ToList(); }
    }

    public Dictionary<string, List<InboxItem>> Snapshot()
    {
        lock (_gate) return _bySource.ToDictionary(s => s.Key, s => s.Value.Values.ToList());
    }

    static Dictionary<string, InboxItem> Index(IEnumerable<InboxItem> items)
    {
        var d = new Dictionary<string, InboxItem>();
        foreach (var i in items) d.TryAdd(i.Key, i);
        return d;
    }
}
```

```csharp
namespace GhNotify.Core;

public enum ToastAction { Show, Remove }

public sealed record ToastRequest(ToastAction Action, string Tag, string? Title = null, string? Body = null, string? Url = null);

public static class NotificationPolicy
{
    public const string SummaryTag = "summary";

    public static IReadOnlyList<ToastRequest> Plan(InboxDiff diff, bool inWorkHours)
    {
        var plan = new List<ToastRequest>();
        foreach (var r in diff.Removed)
        {
            plan.Add(new ToastRequest(ToastAction.Remove, ItemTag.For(r.Key)));
            plan.Add(new ToastRequest(ToastAction.Remove, ItemTag.ForAgent(r.Key)));
        }
        if (!inWorkHours) return plan;
        foreach (var a in diff.Added)
            plan.Add(new ToastRequest(ToastAction.Show, ItemTag.For(a.Key), TitleFor(a), $"{a.Repo}: {a.Title}", a.Url));
        if (diff.InitialLoad.Count > 0)
        {
            var n = diff.InitialLoad.Count;
            plan.Add(new ToastRequest(ToastAction.Show, SummaryTag, $"{n} item{(n == 1 ? "" : "s")} waiting on you",
                string.Join("\n", diff.InitialLoad.Take(3).Select(i => $"{i.Repo}: {i.Title}"))));
        }
        return plan;
    }

    public static string TitleFor(InboxItem i) => i.Kind switch
    {
        ItemKind.ReviewRequested => "Review requested",
        ItemKind.ApprovalPending => "Approval needed",
        ItemKind.MyPrCiFailing => "Your PR is failing",
        _ => "Your PR needs a response",
    };
}
```

```csharp
using System.Text.Json;

namespace GhNotify.Core;

public sealed class AppState
{
    public Dictionary<string, List<InboxItem>> Snapshot { get; set; } = new();
    public List<AgentRun> AgentRuns { get; set; } = [];
}

public sealed class StateStore(string path)
{
    readonly object _gate = new();

    public AppState Load()
    {
        lock (_gate)
        {
            if (!File.Exists(path)) return new AppState();
            try
            {
                return JsonSerializer.Deserialize<AppState>(File.ReadAllText(path), Json.Options) ?? new AppState();
            }
            catch (JsonException ex)
            {
                Log.Error($"state.json unreadable, starting fresh: {ex.Message}");
                File.Move(path, path + ".bad", overwrite: true);
                return new AppState();
            }
        }
    }

    public void Save(AppState state)
```

```csharp
namespace GhNotify.Core;

public sealed class Poller(ISourceCatalog catalog, Reconciler reconciler, TimeSpan sourceTimeout, TimeProvider? time = null)
{
    readonly SemaphoreSlim _gate = new(1, 1);
    readonly TimeProvider _time = time ?? TimeProvider.System;

    public event Action<InboxDiff>? Polled;
    public DateTimeOffset? LastPolledAt { get; private set; }

    public async Task<InboxDiff> PollOnceAsync(CancellationToken ct)
    {
        await _gate.WaitAsync(ct);
        try
        {
            var sources = await catalog.GetSourcesAsync(ct);
            var fetched = await Task.WhenAll(sources.Select(async s => (s.Name, Result: await FetchOne(s, ct))));
            var results = new Dictionary<string, SourceResult>();
            foreach (var (name, result) in fetched) results.TryAdd(name, result);
            var now = _time.GetUtcNow();
            var diff = reconciler.Apply(results, now);
            LastPolledAt = now;
            Polled?.Invoke(diff);
            return diff;
        }
        finally
        {
            _gate.Release();
        }
    }

    public async Task RunAsync(Func<TimeSpan> interval, CancellationToken ct)
    {
        while (!ct.IsCancellationRequested)
        {
            try
            {
                await PollOnceAsync(ct);
            }
            catch (OperationCanceledException) when (ct.IsCancellationRequested)
            {
                return;
            }
            catch (Exception ex)
            {
                Log.Error("poll failed", ex);
            }
            try
            {
                await Task.Delay(interval(), ct);
            }
            catch (OperationCanceledException)
            {
                return;
            }
        }
    }

    async Task<SourceResult> FetchOne(IInboxSource source, CancellationToken ct)
    {
        using var cts = CancellationTokenSource.CreateLinkedTokenSource(ct);
        cts.CancelAfter(sourceTimeout);
        try
        {
            return await source.FetchAsync(cts.Token);
        }
        catch (OperationCanceledException) when (!ct.IsCancellationRequested)
        {
            return SourceResult.Fail($"timed out after {sourceTimeout.TotalSeconds:0.#}s");
        }
        catch (Exception ex) when (ex is not OperationCanceledException)
        {
            Log.Error($"source {source.Name} failed", ex);
            return SourceResult.Fail(ex.Message);
        }
    }
}
```

```csharp
using GhNotify.Core;

namespace GhNotify.GitHub;

public sealed class GhTokenProvider(IProcessRunner runner, TimeProvider? time = null) : ITokenProvider
{
    readonly TimeProvider _time = time ?? TimeProvider.System;
    readonly SemaphoreSlim _gate = new(1, 1);
    string? _token;
    DateTimeOffset _expires;

    public async Task<string> GetTokenAsync(bool forceRefresh, CancellationToken ct)
    {
        await _gate.WaitAsync(ct);
        try
        {
            var now = _time.GetUtcNow();
            if (!forceRefresh && _token is not null && now < _expires) return _token;
            ProcessResult r;
            try
            {
                r = await runner.RunAsync(new ProcessSpec("gh", ["auth", "token"], Timeout: TimeSpan.FromSeconds(15)), ct);
            }
            catch (FileNotFoundException)
            {
                throw new SourceAuthException("GitHub CLI (gh) not found — install it and run `gh auth login`");
            }
            var token = r.StdOut.Trim();
            if (r.ExitCode != 0 || token.Length == 0)
                throw new SourceAuthException("gh is not logged in — run `gh auth login`");
            _token = token;
            _expires = now.AddMinutes(30);
            return token;
        }
        finally
        {
            _gate.Release();
        }
    }
}
```

```csharp
namespace GhNotify.GitHub;

public sealed class GitHubClient
{
    static readonly Uri Api = new("https://api.github.com/");
    readonly HttpClient _http;
    readonly ITokenProvider _tokens;
    readonly TimeProvider _time;
    DateTimeOffset _blockedUntil;

    public GitHubClient(HttpClient http, ITokenProvider tokens, TimeProvider? time = null)
    {
        _http = http;
        _tokens = tokens;
        _time = time ?? TimeProvider.System;
    }

    public async Task<JsonElement> GraphQLAsync(string query, object variables, CancellationToken ct)
    {
        var body = JsonSerializer.Serialize(new { query, variables });
        var root = await SendAsync(() => new HttpRequestMessage(HttpMethod.Post, new Uri(Api, "graphql"))
        {
            Content = new StringContent(body, Encoding.UTF8, "application/json"),
        }, ct);
        if (root.Obj("data").ValueKind != JsonValueKind.Object)
        {
            var message = root.Arr("errors").Select(e => e.Str("message")).FirstOrDefault() ?? "no data";
            throw new HttpRequestException($"GitHub GraphQL: {message}");
        }
        return root.GetProperty("data");
    }

    public Task<JsonElement> GetAsync(string relativePath, CancellationToken ct) =>
        SendAsync(() => new HttpRequestMessage(HttpMethod.Get, new Uri(Api, relativePath)), ct);

    async Task<JsonElement> SendAsync(Func<HttpRequestMessage> make, CancellationToken ct)
    {
        var now = _time.GetUtcNow();
        if (now < _blockedUntil) throw new RateLimitedException(_blockedUntil);
        for (var attempt = 0; ; attempt++)
        {
            var token = await _tokens.GetTokenAsync(attempt > 0, ct);
            using var req = make();
            req.Headers.Authorization = new AuthenticationHeaderValue("Bearer", token);
            req.Headers.UserAgent.ParseAdd("gh-notify/1.0");
            req.Headers.Accept.ParseAdd("application/vnd.github+json");
            req.Headers.Add("X-GitHub-Api-Version", "2022-11-28");
            using var resp = await _http.SendAsync(req, ct);
            if (resp.StatusCode == HttpStatusCode.Unauthorized)
            {
                if (attempt == 0) continue;
                throw new SourceAuthException("GitHub rejected the gh token — run `gh auth login`");
            }
            if (IsRateLimited(resp))
            {
                _blockedUntil = RetryAt(resp, now);
                throw new RateLimitedException(_blockedUntil);
            }
            var text = await resp.Content.ReadAsStringAsync(ct);
            if (!resp.IsSuccessStatusCode)
                throw new HttpRequestException(
                    $"GitHub {(int)resp.StatusCode} for {req.RequestUri!.AbsolutePath}: {Truncate(text)}", null, resp.StatusCode);
            using var doc = JsonDocument.Parse(text);
            return doc.RootElement.Clone();
        }
    }

    static bool IsRateLimited(HttpResponseMessage resp) =>
        resp.StatusCode == HttpStatusCode.TooManyRequests ||
        (resp.StatusCode == HttpStatusCode.Forbidden &&
         (resp.Headers.RetryAfter is not null ||
          (resp.Headers.TryGetValues("x-ratelimit-remaining", out var v) && v.FirstOrDefault() == "0")));

    static DateTimeOffset RetryAt(HttpResponseMessage resp, DateTimeOffset now)
    {
        if (resp.Headers.RetryAfter?.Delta is { } delta) return now + delta;
        if (resp.Headers.TryGetValues("x-ratelimit-reset", out var reset) && long.TryParse(reset.FirstOrDefault(), out var epoch))
            return DateTimeOffset.FromUnixTimeSeconds(epoch);
        return now.AddMinutes(5);
    }

    static string Truncate(string s) => s.Length <= 300 ? s : s[..300] + "…";
}
```

```csharp
using System.Text.Json;
using GhNotify.Core;

namespace GhNotify.GitHub;

public static class GitHubPrMapper
{
    public static IEnumerable<InboxItem> ReviewRequests(JsonElement data)
    {
        var me = data.Obj("viewer").Str("login");
        foreach (var node in data.Obj("review").Arr("nodes"))
        {
            if (node.Int("number") is null) continue;
            var item = Base(node, ItemKind.ReviewRequested, "gh:review", null);
            if (!string.Equals(item.Author, me, StringComparison.OrdinalIgnoreCase)) yield return item;
        }
    }

    public static IEnumerable<InboxItem> MyPrs(JsonElement data)
    {
        var me = data.Obj("viewer").Str("login");
        foreach (var node in data.Obj("mine").Arr("nodes"))
        {
            if (node.Int("number") is null) continue;
            var state = node.Obj("commits").Arr("nodes").Select(n => n.Obj("commit").Obj("statusCheckRollup").Str("state")).FirstOrDefault();
            if (state is "FAILURE" or "ERROR")
                yield return Base(node, ItemKind.MyPrCiFailing, "gh:cifail", "Checks failing");

            var parts = new List<string>();
            if (node.Str("reviewDecision") == "CHANGES_REQUESTED") parts.Add("Changes requested");
            var unresolved = node.Obj("reviewThreads").Arr("nodes").Count(t =>
                !t.Bool("isResolved") &&
                !string.Equals(t.Obj("comments").Arr("nodes").LastOrDefault().Obj("author").Str("login"), me, StringComparison.OrdinalIgnoreCase));
            if (unresolved > 0) parts.Add($"{unresolved} unresolved thread{(unresolved == 1 ? "" : "s")}");
            if (parts.Count > 0)
                yield return Base(node, ItemKind.MyPrNeedsResponse, "gh:respond", string.Join(", ", parts));
        }
    }

    static InboxItem Base(JsonElement n, ItemKind kind, string prefix, string? detail)
    {
        var repo = n.Obj("repository").Str("nameWithOwner") ?? "?";
        var number = n.Int("number")!.Value;
        var author = n.Obj("author");
        var login = author.Str("login") ?? "ghost";
        if (author.Str("__typename") == "Bot" && !login.EndsWith("[bot]", StringComparison.Ordinal)) login += "[bot]";
        int? lines = n.Int("additions") is { } a && n.Int("deletions") is { } d ? a + d : null;
        return new InboxItem($"{prefix}:{repo}#{number}", Provider.GitHub, kind, repo, n.Str("title") ?? "", n.Str("url") ?? "",
            login, n.Date("updatedAt"), n.Str("headRefOid"), lines, detail)
        {
            Number = number,
            SourceRef = $"pull/{number}/head",
            CloneUrl = n.Obj("repository").Str("url"),
        };
    }
}
```

```csharp
using System.Collections.Concurrent;
using System.Net;
using GhNotify.Core;

namespace GhNotify.GitHub;

public sealed class GitHubApprovals(GitHubClient client, TimeProvider? time = null)
{
    readonly TimeProvider _time = time ?? TimeProvider.System;

    public async Task<IReadOnlyList<InboxItem>> FetchAsync(IEnumerable<string> extraRepos, CancellationToken ct)
    {
        var since = _time.GetUtcNow().AddDays(-7).UtcDateTime.ToString("yyyy-MM-ddTHH:mm:ssZ");
        var notes = await client.GetAsync($"notifications?all=true&per_page=50&since={since}", ct);
        var repos = new HashSet<string>(StringComparer.OrdinalIgnoreCase);
        foreach (var n in notes.EnumerateArray())
            if (n.Str("reason") == "approval_requested" && n.Obj("repository").Str("full_name") is { } name)
                repos.Add(name);
        foreach (var r in extraRepos) repos.Add(r);

        var items = new ConcurrentBag<InboxItem>();
        await Parallel.ForEachAsync(repos, new ParallelOptions { MaxDegreeOfParallelism = 4, CancellationToken = ct }, async (repo, ct2) =>
        {
            foreach (var item in await RepoAsync(repo.ToLowerInvariant(), ct2)) items.Add(item);
        });
        return items.ToList();
    }

    async Task<IReadOnlyList<InboxItem>> RepoAsync(string repo, CancellationToken ct)
    {
        System.Text.Json.JsonElement runs;
        try
        {
            runs = await client.GetAsync($"repos/{repo}/actions/runs?status=waiting&per_page=20", ct);
        }
        catch (HttpRequestException ex) when (ex.StatusCode is HttpStatusCode.NotFound or HttpStatusCode.Forbidden)
        {
            Log.Info($"skipping approvals for {repo}: {(int?)ex.StatusCode}");
            return [];
        }
        var items = new List<InboxItem>();
        foreach (var run in runs.Arr("workflow_runs"))
        {
            var id = run.Long("id");
            if (id is null) continue;
            var pending = await client.GetAsync($"repos/{repo}/actions/runs/{id}/pending_deployments", ct);
            var envs = pending.EnumerateArray()
                .Where(p => p.Bool("current_user_can_approve"))
                .Select(p => p.Obj("environment").Str("name") ?? "?")
                .ToList();
            if (envs.Count == 0) continue;
            items.Add(new InboxItem($"gh:approval:{repo}/runs/{id}", Provider.GitHub, ItemKind.ApprovalPending, repo,
                $"{run.Str("name")}: {run.Str("display_title")}", run.Str("html_url") ?? "", run.Obj("actor").Str("login") ?? "",
                run.Date("updated_at"), run.Str("head_sha"), null, $"Environment: {string.Join(", ", envs)}")
            {
                CloneUrl = $"https://github.com/{repo}",
            });
        }
        return items;
    }
}
```

```csharp
using System.Globalization;
using System.Text.Json;
using GhNotify.Core;

namespace GhNotify.Ado;

public sealed class AzTokenProvider(IProcessRunner runner, TimeProvider? time = null) : ITokenProvider
{
    public const string AdoResource = "499b84ac-1321-427f-aa17-267ca6975798";
    readonly TimeProvider _time = time ?? TimeProvider.System;
    readonly SemaphoreSlim _gate = new(1, 1);
    string? _token;
    DateTimeOffset _expires;

    public async Task<string> GetTokenAsync(bool forceRefresh, CancellationToken ct)
    {
        await _gate.WaitAsync(ct);
        try
        {
            if (!forceRefresh && _token is not null && _time.GetUtcNow() < _expires.AddMinutes(-5)) return _token;
            ProcessResult r;
            try
            {
                r = await runner.RunAsync(new ProcessSpec("az",
                    ["account", "get-access-token", "--resource", AdoResource, "--output", "json"], Timeout: TimeSpan.FromSeconds(30)), ct);
            }
            catch (FileNotFoundException)
            {
                throw new SourceAuthException("Azure CLI (az) not found — install it and run `az login`");
            }
            if (r.ExitCode != 0 || r.TimedOut)
                throw new SourceAuthException("az is not logged in or the token expired — run `az login`");
            using var doc = JsonDocument.Parse(r.StdOut);
            var root = doc.RootElement;
            _token = root.Str("accessToken") ?? throw new SourceAuthException("az returned no access token — run `az login`");
            _expires = ParseExpiry(root);
            return _token;
        }
        finally
        {
            _gate.Release();
        }
    }

    static DateTimeOffset ParseExpiry(JsonElement root)
    {
        if (root.Long("expires_on") is { } epoch) return DateTimeOffset.FromUnixTimeSeconds(epoch);
        if (long.TryParse(root.Str("expires_on"), out var epochStr)) return DateTimeOffset.FromUnixTimeSeconds(epochStr);
        if (DateTime.TryParse(root.Str("expiresOn"), CultureInfo.InvariantCulture, DateTimeStyles.AssumeLocal, out var local))
            return new DateTimeOffset(local);
        return DateTimeOffset.UtcNow.AddMinutes(10);
    }
}
```

```csharp
using System.Net;
using System.Net.Http.Headers;
using System.Text.Json;
using GhNotify.Core;

namespace GhNotify.Ado;

public sealed class AdoClient(HttpClient http, ITokenProvider tokens, TimeProvider? time = null)
{
    readonly TimeProvider _time = time ?? TimeProvider.System;
    DateTimeOffset _blockedUntil;

    public async Task<JsonElement> GetAsync(string absoluteUrl, CancellationToken ct)
    {
        var now = _time.GetUtcNow();
        if (now < _blockedUntil) throw new RateLimitedException(_blockedUntil);
        for (var attempt = 0; ; attempt++)
        {
            var token = await tokens.GetTokenAsync(attempt > 0, ct);
            using var req = new HttpRequestMessage(HttpMethod.Get, absoluteUrl);
            req.Headers.Authorization = new AuthenticationHeaderValue("Bearer", token);
            req.Headers.Accept.ParseAdd("application/json");
            using var resp = await http.SendAsync(req, ct);
            if (resp.StatusCode is HttpStatusCode.Unauthorized or HttpStatusCode.NonAuthoritativeInformation)
            {
                if (attempt == 0) continue;
                throw new SourceAuthException("Azure DevOps rejected the az token — run `az login`");
            }
            if (resp.StatusCode == HttpStatusCode.TooManyRequests)
            {
                _blockedUntil = now + (resp.Headers.RetryAfter?.Delta ?? TimeSpan.FromMinutes(5));
                throw new RateLimitedException(_blockedUntil);
            }
            var text = await resp.Content.ReadAsStringAsync(ct);
            if (!resp.IsSuccessStatusCode)
                throw new HttpRequestException(
                    $"Azure DevOps {(int)resp.StatusCode} for {new Uri(absoluteUrl).AbsolutePath}: {(text.Length > 300 ? text[..300] + "…" : text)}",
                    null, resp.StatusCode);
            using var doc = JsonDocument.Parse(text);
            return doc.RootElement.Clone();
        }
    }
}
```

```csharp
using System.Collections.Concurrent;
using GhNotify.Core;

namespace GhNotify.Ado;

public sealed class AdoSourceCatalog(
    AdoDirectory directory,
    Func<AdoConfig> config,
    Func<string, IInboxSource> createOrgSource,
    TimeProvider? time = null) : ISourceCatalog
{
    readonly TimeProvider _time = time ?? TimeProvider.System;
    readonly ConcurrentDictionary<string, IInboxSource> _sources = new(StringComparer.OrdinalIgnoreCase);
    IReadOnlyList<string>? _discovered;
    DateTimeOffset _discoveredAt;
    string? _discoveryProblem;

    public async Task<IReadOnlyList<IInboxSource>> GetSourcesAsync(CancellationToken ct)
    {
        var cfg = config();
        if (!cfg.Enabled) return [];

        if (cfg.DiscoverOrgs && (_discovered is null || _time.GetUtcNow() - _discoveredAt > TimeSpan.FromHours(1)))
        {
            try
            {
                _discovered = await directory.DiscoverOrgsAsync(ct);
                _discoveredAt = _time.GetUtcNow();
                _discoveryProblem = null;
            }
            catch (Exception ex) when (ex is not OperationCanceledException)
            {
                // Keep the last good list (if any) so a token blip never drops orgs.
                _discoveryProblem = ex.Message;
                Log.Error("ADO org discovery failed", ex);
            }
        }

        var orgs = new HashSet<string>(cfg.Orgs, StringComparer.OrdinalIgnoreCase);
        if (cfg.DiscoverOrgs && _discovered is not null) orgs.UnionWith(_discovered);
        orgs.ExceptWith(cfg.ExcludeOrgs);

        if (orgs.Count == 0 && _discoveryProblem is not null)
            return [new FailedSource("ADO", _discoveryProblem)];
        return orgs.Order(StringComparer.OrdinalIgnoreCase).Select(o => _sources.GetOrAdd(o, createOrgSource)).ToList();
    }
}
```

`HashSet.ExceptWith` uses the set's own comparer, so exclusion is case-insensitive.

```csharp
    {
        var baseUrl = ProjectUrl(org, p);
        var prs = await c.GetAsync($"{baseUrl}/_apis/git/pullrequests?searchCriteria.status=active&$top=1000&api-version=7.1", ct);
        var items = new List<InboxItem>();

    public static bool ReviewWaiting(JsonElement pr, AdoOrgContext ctx, bool includeDrafts)
    {
        if (!includeDrafts && pr.Bool("isDraft")) return false;
        var reviewers = pr.Arr("reviewers").ToList();
        var mine = reviewers.Where(r => string.Equals(r.Str("id"), ctx.MyId, StringComparison.OrdinalIgnoreCase)).ToList();

        if (failing > 0)

        if (others.Any(r => r.Int("vote") == -10)) parts.Add("Rejected");
        else if (others.Any(r => r.Int("vote") == -5)) parts.Add("Waiting for author");
```

```csharp
public sealed class AdoOrgSource(string org, AdoClient client, AdoDirectory directory, Func<AdoConfig> config) : IInboxSource
{
    readonly ConcurrentDictionary<string, IReadOnlyList<InboxItem>> _lastByProject = new();

    public string Name => $"ADO:{org}";

    public async Task<SourceResult> FetchAsync(CancellationToken ct)
    {
        try
        {
            var cfg = config();
            var ctx = await directory.GetOrgContextAsync(org, ct);
            var projects = await directory.GetProjectsAsync(org, ct);
            var all = new ConcurrentBag<InboxItem>();
            await Parallel.ForEachAsync(projects, new ParallelOptions { MaxDegreeOfParallelism = 4, CancellationToken = ct }, async (p, ct2) =>
            {
                IReadOnlyList<InboxItem> items;
                try
                {
                    items = await FetchProjectAsync(p, ctx, cfg, ct2);
                    _lastByProject[p.Id] = items;
                }
                catch (Exception ex) when (ex is HttpRequestException or JsonException)
                {
                    Log.Error($"ADO {org}/{p.Name} skipped this poll: {ex.Message}");
                    items = _lastByProject.GetValueOrDefault(p.Id) ?? [];
                }
                foreach (var i in items) all.Add(i);
            });
            return SourceResult.Ok(all.ToList());
        }
        catch (Exception ex) when (ex is SourceAuthException or RateLimitedException or HttpRequestException or JsonException)
        {
            return SourceResult.Fail(ex.Message);
        }
    }

    async Task<IReadOnlyList<InboxItem>> FetchProjectAsync(AdoProject p, AdoOrgContext ctx, AdoConfig cfg, CancellationToken ct)
    {
        var items = new List<InboxItem>();
        items.AddRange(await AdoPullRequests.FetchAsync(client, org, p, ctx, cfg.IncludeDrafts, ct));
        return items;
    }
```

```csharp
namespace GhNotify.Agents;

public static class RemoteUrl
{
    static readonly Regex Scp = new(@"^(?:[^@/]+@)?(?<host>[^:/\\]{2,}):(?<path>[^/\\].*)$", RegexOptions.Compiled);

    public static string? Normalize(string url)
    {
        url = url.Trim();
        if (url.EndsWith(".git", StringComparison.OrdinalIgnoreCase)) url = url[..^4];
        url = url.TrimEnd('/');

        string host, path;
        if (url.Contains("://"))
        {
            if (!Uri.TryCreate(url, UriKind.Absolute, out var u)) return null;
            host = u.Host;
            path = Uri.UnescapeDataString(u.AbsolutePath);
        }
        else if (Scp.Match(url) is { Success: true } m)
        {
            host = m.Groups["host"].Value;
            path = Uri.UnescapeDataString(m.Groups["path"].Value);
        }
        else return null;

        host = host.ToLowerInvariant();
        var segs = path.Split('/', StringSplitOptions.RemoveEmptyEntries).ToList();
        string? result = null;

        if (host is "github.com" or "ssh.github.com")
            result = segs.Count >= 2 ? $"github.com/{segs[0]}/{segs[1]}" : null;
        else if (host is "ssh.dev.azure.com" or "vs-ssh.visualstudio.com")
            result = segs.Count == 4 && segs[0] == "v3" ? $"dev.azure.com/{segs[1]}/{segs[2]}/{segs[3]}" : null;
        else if (host == "dev.azure.com")
            result = Ado(segs.Skip(1).ToList(), segs.FirstOrDefault());
        else if (host.EndsWith(".visualstudio.com", StringComparison.Ordinal))
        {
            if (segs.Count > 0 && segs[0].Equals("DefaultCollection", StringComparison.OrdinalIgnoreCase)) segs.RemoveAt(0);
            result = Ado(segs, host.Split('.')[0]);
        }
        return result?.ToLowerInvariant();
    }

    /// <summary>segs after the org: "project/_git/repo" or "_git/repo" (project named like the repo).</summary>
    static string? Ado(List<string> segs, string? org)
    {
        if (org is null) return null;
        if (segs.Count == 3 && segs[1] == "_git") return $"dev.azure.com/{org}/{segs[0]}/{segs[2]}";
        if (segs.Count == 2 && segs[0] == "_git") return $"dev.azure.com/{org}/{segs[1]}/{segs[1]}";
        return null;
    }
}
```

```csharp
using GhNotify.Core;

namespace GhNotify.Agents;

public interface ILocalRepoIndex
{
    string? FindClone(string cloneUrl);
}

public sealed class RepoLocator(Func<IReadOnlyList<string>> roots, int maxDepth = 3, TimeProvider? time = null) : ILocalRepoIndex
{
    static readonly HashSet<string> Skip = new(StringComparer.OrdinalIgnoreCase) { "node_modules", "bin", "obj", "packages" };
    readonly TimeProvider _time = time ?? TimeProvider.System;
    readonly object _gate = new();
    Dictionary<string, string>? _map;
    DateTimeOffset _scannedAt;

    public string? FindClone(string cloneUrl)
    {
        var key = RemoteUrl.Normalize(cloneUrl);
        if (key is null) return null;
        lock (_gate)
        {
            var age = _time.GetUtcNow() - _scannedAt;
            if (_map is null || age > TimeSpan.FromHours(1)) Rescan();
            if (_map!.TryGetValue(key, out var path)) return path;
            if (age > TimeSpan.FromMinutes(5))
            {
                Rescan();
                return _map.GetValueOrDefault(key);
            }
            return null;
        }
    }

    public void Rescan()
    {
        var map = new Dictionary<string, string>();
        foreach (var root in roots())
            if (Directory.Exists(root)) Walk(root, 0, map);
        lock (_gate)
        {
            _map = map;
            _scannedAt = _time.GetUtcNow();
        }
        Log.Info($"repo scan found {map.Count} clones");
    }

    void Walk(string dir, int depth, Dictionary<string, string> map)
    {
        var dotGit = Path.Combine(dir, ".git");
        if (Directory.Exists(dotGit))
        {
            if (ReadOriginUrl(Path.Combine(dotGit, "config")) is { } url && RemoteUrl.Normalize(url) is { } key)
                map.TryAdd(key, dir);
            return;
        }
        if (File.Exists(dotGit) || depth >= maxDepth) return; // .git file = worktree/submodule, not a main clone
        IEnumerable<string> subs;
        try { subs = Directory.EnumerateDirectories(dir); }
        catch (Exception ex) when (ex is UnauthorizedAccessException or IOException) { return; }
        foreach (var sub in subs)
        {
            var name = Path.GetFileName(sub);
            if (name.StartsWith('.') || Skip.Contains(name)) continue;
            Walk(sub, depth + 1, map);
        }
    }

    public static string? ReadOriginUrl(string gitConfigPath)
    {
        if (!File.Exists(gitConfigPath)) return null;
        var inOrigin = false;
        foreach (var raw in File.ReadLines(gitConfigPath))
        {
            var line = raw.Trim();
            if (line.StartsWith('['))
            {
                inOrigin = line.Replace(" ", "").Equals("[remote\"origin\"]", StringComparison.OrdinalIgnoreCase);
                continue;
            }
            if (inOrigin && line.StartsWith("url", StringComparison.OrdinalIgnoreCase) && line.IndexOf('=') is var eq and > 0)
                return line[(eq + 1)..].Trim();
        }
        return null;
    }
}
```

```csharp
using GhNotify.Core;

namespace GhNotify.Agents;

public interface IWorktreeManager
{
    Task<string> CreateAsync(string clonePath, string fetchRef, string tag, CancellationToken ct);
    Task RemoveAsync(string clonePath, string worktreePath, string tag, CancellationToken ct);
}

public sealed class GitException(string message) : Exception(message);

public sealed class WorktreeManager(IProcessRunner runner, string baseDir) : IWorktreeManager
{
    public async Task<string> CreateAsync(string clonePath, string fetchRef, string tag, CancellationToken ct)
    {
        var wt = Path.Combine(baseDir, tag);
        if (Directory.Exists(wt)) await RemoveAsync(clonePath, wt, tag, ct);
        var localRef = $"refs/ghnotify/{tag}";
        var src = fetchRef.StartsWith("refs/", StringComparison.Ordinal) ? fetchRef
            : fetchRef.StartsWith("pull/", StringComparison.Ordinal) ? "refs/" + fetchRef
            : "refs/heads/" + fetchRef;
        await Git(clonePath, ct, "fetch", "--no-tags", "origin", $"+{src}:{localRef}");
        Directory.CreateDirectory(baseDir);
        await Git(clonePath, ct, "worktree", "add", "--detach", wt, localRef);
        return wt;
    }

    public async Task RemoveAsync(string clonePath, string worktreePath, string tag, CancellationToken ct)
    {
        await TryGit(clonePath, ct, "worktree", "remove", "--force", worktreePath);
        if (Directory.Exists(worktreePath)) ForceDelete(worktreePath);
        await TryGit(clonePath, ct, "worktree", "prune");
        await TryGit(clonePath, ct, "update-ref", "-d", $"refs/ghnotify/{tag}");
    }

    async Task Git(string repo, CancellationToken ct, params string[] args)
    {
        var r = await runner.RunAsync(new ProcessSpec("git", ["-C", repo, .. args], Timeout: TimeSpan.FromMinutes(5)), ct);
        if (r.ExitCode != 0 || r.TimedOut)
            throw new GitException($"git {string.Join(' ', args)} failed: {(r.TimedOut ? "timed out" : r.StdErr.Trim())}");
    }

    async Task TryGit(string repo, CancellationToken ct, params string[] args)
    {
        try { await Git(repo, ct, args); }
        catch (GitException ex) { Log.Info(ex.Message); }
    }

    static void ForceDelete(string dir)
    {
        try
        {
            foreach (var f in Directory.EnumerateFiles(dir, "*", SearchOption.AllDirectories))
                File.SetAttributes(f, FileAttributes.Normal);
            Directory.Delete(dir, recursive: true);
        }
        catch (Exception ex) when (ex is IOException or UnauthorizedAccessException)
        {
            Log.Error($"could not delete {dir}", ex);
        }
    }
}
```

- The prompt goes to `claude` on **stdin**, never in argv. This avoids cmd.exe quoting when `claude` is a `.cmd` shim.
- **Auto** (`manual: false`) never starts if any run exists for the key. **Manual** starts unless one is Queued or Running.

- `OnItemAdded` for a key with a run (the item came back) clears `ItemRemovedAt`. It marks the run Outdated if the head differs (Review Focus 4).
- Sweep: a run whose item left the inbox is deleted, together with its worktree, if it was not opened in the last 24 h or if the item left ≥ 24 h ago. Queued and Running runs are never swept.
- Restored runs in Queued or Running become `Failed` with "Interrupted by app restart".

```csharp
using System.Text.Json;
using GhNotify.Core;

namespace GhNotify.Agents;

public sealed record AgentOutcome(bool Success, string? SessionId, string? Summary, decimal? CostUsd, string? Error);

public interface IClaudeRunner
{
    Task<AgentOutcome> RunAsync(string workingDir, string prompt, AgentProfile profile, IReadOnlyList<string> globalAllowed,
        TimeSpan timeout, CancellationToken ct);
}

public static class AgentSafety
{
    /// <summary>Always passed to unattended runs. Best-effort second line of defence behind the prompt (spec §7 trust boundary).</summary>
    public static readonly IReadOnlyList<string> DisallowedTools =
    [
        "Bash(gh pr review:*)", "Bash(gh pr comment:*)", "Bash(gh pr merge:*)", "Bash(gh pr close:*)", "Bash(gh pr edit:*)",
        "Bash(gh pr ready:*)", "Bash(gh issue comment:*)",
        "Bash(gh api -X POST:*)", "Bash(gh api -X PATCH:*)", "Bash(gh api -X PUT:*)", "Bash(gh api -X DELETE:*)",
        "Bash(gh api --method POST:*)", "Bash(gh api --method PATCH:*)", "Bash(gh api --method PUT:*)", "Bash(gh api --method DELETE:*)",
        "Bash(git push:*)", "Bash(git commit:*)",
        "Bash(az repos pr create:*)", "Bash(az repos pr update:*)", "Bash(az repos pr set-vote:*)", "Bash(az repos pr reviewer:*)",
        "Bash(az repos pr work-item:*)", "Bash(az pipelines run:*)", "Bash(az rest:*)",
    ];
}

public sealed class ClaudeRunner(IProcessRunner runner) : IClaudeRunner
{
    public async Task<AgentOutcome> RunAsync(string workingDir, string prompt, AgentProfile profile, IReadOnlyList<string> globalAllowed,
        TimeSpan timeout, CancellationToken ct)
    {
        var result = await runner.RunAsync(new ProcessSpec("claude", BuildArgs(profile, globalAllowed),
            WorkingDirectory: workingDir, StdIn: prompt, Timeout: timeout), ct);
        return Parse(result);
    }

    public static IReadOnlyList<string> BuildArgs(AgentProfile profile, IReadOnlyList<string> globalAllowed)
    {
        var args = new List<string> { "-p", "--output-format", "json", "--permission-mode", "default" };
        var allowed = globalAllowed.Concat(profile.AllowedTools).Distinct().ToList();
        if (allowed.Count > 0)
        {
            args.Add("--allowedTools");
            args.AddRange(allowed);
        }
        args.Add("--disallowedTools");
        args.AddRange(AgentSafety.DisallowedTools.Concat(profile.DisallowedTools).Distinct());
        return args;
    }

    public static AgentOutcome Parse(ProcessResult r)
    {
        if (r.TimedOut) return new AgentOutcome(false, null, null, null, "timed out");
        var start = r.StdOut.IndexOf('{');
        try
        {
            if (start < 0) throw new JsonException("no JSON in output");
            using var doc = JsonDocument.Parse(r.StdOut[start..]);
            var root = doc.RootElement;
            var sid = root.Str("session_id");
            var text = root.Str("result");
            decimal? cost = root.ValueKind == JsonValueKind.Object && root.TryGetProperty("total_cost_usd", out var c) && c.TryGetDecimal(out var d) ? d : null;
            if (root.Bool("is_error") || r.ExitCode != 0)
                return new AgentOutcome(false, sid, ExtractSummary(text), cost, Tail(text ?? r.StdErr));
            return new AgentOutcome(true, sid, ExtractSummary(text), cost, null);
        }
        catch (JsonException)
        {
            return new AgentOutcome(false, null, null, null, Tail(r.StdErr.Length > 0 ? r.StdErr : r.StdOut));
        }
    }

    public static string? ExtractSummary(string? result)
    {
        if (result is null) return null;
        var lines = result.Split('\n').Select(l => l.Trim()).Where(l => l.Length > 0).ToList();
        foreach (var line in Enumerable.Reverse(lines))
        {
            var bare = line.TrimStart('*', '_', ' ');
            if (bare.StartsWith("SUMMARY:", StringComparison.OrdinalIgnoreCase))
                return bare["SUMMARY:".Length..].Trim().Trim('*', '_').Trim();
        }
        return lines.Count == 0 ? null : Truncate(lines[^1], 200);
    }

    static string Tail(string s) => s.Length <= 500 ? s.Trim() : "…" + s[^500..].Trim();
    static string Truncate(string s, int n) => s.Length <= n ? s : s[..n] + "…";
}
```

```csharp
using System.Collections.Concurrent;
using GhNotify.Core;

namespace GhNotify.Agents;

public sealed record AgentDeps(
    ILocalRepoIndex Repos, IWorktreeManager Worktrees, IClaudeRunner Claude, ISkillLocator Skills, Func<bool> ClaudeAvailable);

public sealed class AgentCoordinator : IDisposable
{
    static readonly TimeSpan Keep = TimeSpan.FromHours(24);
    readonly AgentDeps _d;
    readonly Func<AppConfig> _config;
    readonly string _scratch;
    readonly TimeProvider _time;
    readonly object _gate = new();
    readonly ConcurrentDictionary<string, AgentRun> _runs = new();
    readonly ConcurrentDictionary<string, string?> _currentHead = new();
    readonly ConcurrentDictionary<string, Task> _inflight = new();
    readonly SemaphoreSlim _slots;
    readonly CancellationTokenSource _shutdown = new();

    public AgentCoordinator(AgentDeps deps, Func<AppConfig> config, string scratchDir, TimeProvider? time = null, IEnumerable<AgentRun>? restored = null)
    {
        _d = deps;
        _config = config;
        _scratch = scratchDir;
        _time = time ?? TimeProvider.System;
        _slots = new SemaphoreSlim(Math.Max(1, config().MaxConcurrentAgents));
        foreach (var r in restored ?? [])
            _runs[r.Key] = r.State is AgentState.Queued or AgentState.Running
                ? r with { State = AgentState.Failed, Error = "Interrupted by app restart" }
                : r;
    }

    public event Action<AgentRun>? RunChanged;
    public event Action<string>? RunRemoved;

    public IReadOnlyDictionary<string, AgentRun> Runs => _runs;
    public AgentRun? Get(string key) => _runs.GetValueOrDefault(key);
    DateTimeOffset Now => _time.GetUtcNow();

    public string? WhyCannotRun(InboxItem item, AgentDecision decision)
    {
        if (decision.Profile is not { } profile) return "No agent profile for this item";
        if (!_d.ClaudeAvailable()) return "claude CLI not found on PATH";
        string? clone = null;
        if (profile.NeedsWorktree)
        {
            if (item.CloneUrl is null || item.SourceRef is null) return "This item has no branch to check out";
            clone = _d.Repos.FindClone(item.CloneUrl);
            if (clone is null) return "No local clone under repoRoots";
        }
        if (profile.RequiresSkill is { } skill && !_d.Skills.IsInstalled(skill, clone)) return $"Skill /{skill} not installed";
        return null;
    }

    public bool TryStart(InboxItem item, AgentDecision decision, bool manual)
    {
        if (WhyCannotRun(item, decision) is not null) return false;
        var profile = decision.Profile!;
        AgentRun run;
        lock (_gate)
        {
            var existing = Get(item.Key);
            if (existing is { State: AgentState.Queued or AgentState.Running }) return false;
            if (!manual && existing is not null) return false;
            run = new AgentRun
            {
                Key = item.Key,
                Profile = decision.ProfileName!,
                State = AgentState.Queued,
                HeadSha = item.HeadSha,
                ClonePath = profile.NeedsWorktree ? _d.Repos.FindClone(item.CloneUrl!) : null,
                LastOpenedAt = existing?.LastOpenedAt,
            };
            _currentHead[item.Key] = item.HeadSha;
            _runs[item.Key] = run;
        }
        RunChanged?.Invoke(run); // raise Queued before the worker can raise Running
        _inflight[item.Key] = Task.Run(() => ExecuteAsync(item, profile, run.ClonePath));
        return true;
    }

    async Task ExecuteAsync(InboxItem item, AgentProfile profile, string? clone)
    {
        var ct = _shutdown.Token;
        try
        {
            await _slots.WaitAsync(ct);
        }
        catch (OperationCanceledException)
        {
            return;
        }
        try
        {
            Update(item.Key, r => r with { State = AgentState.Running, StartedAt = Now });
            var tag = ItemTag.For(item.Key);
            string cwd;
            if (profile.NeedsWorktree)
            {
                cwd = await _d.Worktrees.CreateAsync(clone!, item.SourceRef!, tag, ct);
            }
            else
            {
                cwd = Path.Combine(_scratch, tag);
                Directory.CreateDirectory(cwd);
            }
            Update(item.Key, r => r with { WorktreePath = cwd });
            var cfg = _config();
            var o = await _d.Claude.RunAsync(cwd, PromptTemplate.Fill(profile.Prompt, item), profile, cfg.AgentAllowedTools,
                TimeSpan.FromMinutes(cfg.AgentTimeoutMinutes), ct);
            Update(item.Key, r => r with
            {
                State = !o.Success ? AgentState.Failed
                    : _currentHead.GetValueOrDefault(item.Key) == r.HeadSha ? AgentState.Ready : AgentState.Outdated,
                SessionId = o.SessionId,
                Summary = o.Summary,
                CostUsd = o.CostUsd,
                Error = o.Error,
                FinishedAt = Now,
            });
        }
        catch (OperationCanceledException) when (ct.IsCancellationRequested)
        {
        }
        catch (Exception ex)
        {
            Log.Error($"agent run for {item.Key} failed", ex);
            Update(item.Key, r => r with { State = AgentState.Failed, Error = ex.Message, FinishedAt = Now });
        }
        finally
        {
            _slots.Release();
            _inflight.TryRemove(item.Key, out _);
        }
    }

    public void OnItemAdded(InboxItem item)
    {
        _currentHead[item.Key] = item.HeadSha;
        if (Get(item.Key) is null) return;
        Update(item.Key, r => r with
        {
            ItemRemovedAt = null,
            State = r.State is AgentState.Ready or AgentState.Failed && r.HeadSha != item.HeadSha ? AgentState.Outdated : r.State,
        });
    }

    public void OnItemChanged(ItemChange change)
    {
        _currentHead[change.New.Key] = change.New.HeadSha;
        if (change.HeadChanged && Get(change.New.Key) is { State: AgentState.Ready or AgentState.Failed })
            Update(change.New.Key, r => r with { State = AgentState.Outdated });
    }

    public void OnItemRemoved(InboxItem item)
    {
        if (Get(item.Key) is { ItemRemovedAt: null })
            Update(item.Key, r => r with { ItemRemovedAt = Now });
    }

    public void MarkOpened(string key)
    {
        if (Get(key) is not null) Update(key, r => r with { LastOpenedAt = Now });
    }

    public async Task SweepAsync(CancellationToken ct)
    {
        foreach (var r in _runs.Values.ToList())
        {
            if (r.ItemRemovedAt is not { } removed || r.State is AgentState.Queued or AgentState.Running) continue;
            var openedRecently = r.LastOpenedAt is { } opened && Now - opened < Keep;
            if (openedRecently && Now - removed < Keep) continue;
            if (r.WorktreePath is { } wt)
            {
                try
                {
                    if (r.ClonePath is { } clone) await _d.Worktrees.RemoveAsync(clone, wt, ItemTag.For(r.Key), ct);
                    else if (Directory.Exists(wt)) Directory.Delete(wt, recursive: true);
                }
                catch (Exception ex) when (ex is IOException or UnauthorizedAccessException)
                {
                    Log.Error($"could not clean {wt}", ex);
                }
            }
            if (_runs.TryRemove(r.Key, out _)) RunRemoved?.Invoke(r.Key);
        }
    }

    public Task WhenIdle() => Task.WhenAll(_inflight.Values.ToList());

    public void Dispose() => _shutdown.Cancel();

    void Update(string key, Func<AgentRun, AgentRun> change)
    {
        AgentRun next;
        lock (_gate)
        {
            if (!_runs.TryGetValue(key, out var current)) return;
            next = change(current);
            _runs[key] = next;
        }
        RunChanged?.Invoke(next);
    }
}
```

```csharp
using System.Text.Json;

namespace GhNotify.Core;

public sealed class HookDispatcher(IProcessRunner runner, Func<AppConfig> config)
{
    public Task DispatchAsync(HookEvent ev, InboxItem item, AgentRun? run = null)
    {
        var hooks = config().Hooks
            .Where(h => h.Event == ev && h.Run.Count > 0 && ItemMatcher.Matches(h.Match, item))
            .ToList();
        if (hooks.Count == 0) return Task.CompletedTask;

        var payload = JsonSerializer.Serialize(new { @event = ev.ToString(), item, agent = run }, Json.Options);
        var env = new Dictionary<string, string>
        {
            ["GHN_EVENT"] = ev.ToString(),
            ["GHN_KEY"] = item.Key,
            ["GHN_URL"] = item.Url,
            ["GHN_KIND"] = item.Kind.ToString(),
            ["GHN_REPO"] = item.Repo,
        };
        return Task.WhenAll(hooks.Select(h => RunOne(ev, h, payload, env)));
    }

    async Task RunOne(HookEvent ev, HookConfig hook, string payload, IReadOnlyDictionary<string, string> env)
    {
        var name = string.Join(' ', hook.Run);
        try
        {
            var r = await runner.RunAsync(new ProcessSpec(hook.Run[0], hook.Run.Skip(1).ToList(),
                StdIn: payload, Env: env, Timeout: TimeSpan.FromSeconds(60)));
            if (r.TimedOut || r.ExitCode != 0)
                Log.Error($"hook '{name}' for {ev} exited {r.ExitCode}{(r.TimedOut ? " (timed out)" : "")}: {r.StdErr.Trim()}");
        }
        catch (Exception ex)
        {
            Log.Error($"hook '{name}' for {ev} failed to run", ex);
        }
    }
}
```

The `@event` anonymous member serializes as `event` under the camelCase policy. The `ev.ToString()` value gives `"ItemAdded"`.

```csharp
using System.Globalization;

namespace GhNotify.Core;

public sealed record InboxRow(
    string Key, string ProviderGlyph, string Repo, string Title, string Url, string Age, bool Stale, string? Detail,
    string? BadgeText, string? BadgeTooltip, string? RunButton, bool CanRun, string? RunDisabledReason, bool CanOpenInClaude);

public sealed record InboxSection(string Title, IReadOnlyList<InboxRow> Rows);

public static class InboxPresenter
{
    static readonly (ItemKind Kind, string Title)[] Order =
    [
        (ItemKind.ApprovalPending, "Approvals"),
        (ItemKind.ReviewRequested, "Review requests"),
        (ItemKind.MyPrCiFailing, "My PRs — failing"),
        (ItemKind.MyPrNeedsResponse, "My PRs — needs response"),
    ];

    public static IReadOnlyList<InboxSection> Build(
        IReadOnlyList<InboxEntry> entries,
        Func<string, AgentRun?> runOf,
        Func<InboxItem, AgentDecision> decide,
        Func<InboxItem, AgentDecision, string?> whyCannotRun,
        DateTimeOffset now)
    {
        var sections = new List<InboxSection>();
        foreach (var (kind, title) in Order)
        {
            var rows = entries.Where(e => e.Item.Kind == kind)
                .OrderByDescending(e => e.Item.UpdatedAt)
                .Select(e => Row(e, runOf(e.Item.Key), decide(e.Item), whyCannotRun, now))
                .ToList();
            if (rows.Count > 0) sections.Add(new InboxSection(title, rows));
        }
        return sections;
    }

    static InboxRow Row(InboxEntry e, AgentRun? run, AgentDecision decision, Func<InboxItem, AgentDecision, string?> why, DateTimeOffset now)
    {
        var i = e.Item;
        var busy = run is { State: AgentState.Queued or AgentState.Running };
        string? button = decision.Mode == AgentMode.None || busy ? null : run is null ? LabelFor(decision.ProfileName) : "Re-run";
        var reason = button is null ? null : why(i, decision);
        return new InboxRow(
            i.Key,
            i.Provider == Provider.GitHub ? "GH" : "ADO",
            i.Repo, i.Title, i.Url, Age(now - i.UpdatedAt), e.Stale, i.Detail,
            Badge(run), Tooltip(run),
            button, button is not null && reason is null, reason,
            run is { State: AgentState.Ready or AgentState.Failed or AgentState.Outdated, SessionId: not null, WorktreePath: not null });
    }

    public static string LabelFor(string? profileName) => profileName switch
    {
        "peer-review" => "Pre-review",
        "pr-shepherd" => "Shepherd",
        _ => $"Run {profileName}",
    };

    public static string Age(TimeSpan elapsed) => elapsed switch
    {
        { TotalMinutes: < 1 } => "now",
        { TotalMinutes: < 60 } => $"{(int)elapsed.TotalMinutes}m",
        { TotalHours: < 48 } => $"{(int)elapsed.TotalHours}h",
        _ => $"{(int)elapsed.TotalDays}d",
    };

    static string? Badge(AgentRun? run) => run?.State switch
    {
        AgentState.Queued => "Queued",
        AgentState.Running => "Running…",
        AgentState.Ready => "✓ Ready",
        AgentState.Failed => "✗ Failed",
        AgentState.Outdated => "Outdated",
        _ => null,
    };

    static string? Tooltip(AgentRun? run)
    {
        if (run is null) return null;
        var text = run.Summary ?? run.Error;
        if (run.CostUsd is { } cost) text = $"{text} (${cost.ToString("0.00", CultureInfo.InvariantCulture)})";
        return text;
    }
}
```

```csharp
using System.Diagnostics;
using GhNotify.Ado;
using GhNotify.Agents;
using GhNotify.Core;
using GhNotify.GitHub;

namespace GhNotify.App;

public sealed class AppController : IDisposable
{
    readonly ConfigStore _config;
    readonly StateStore _stateStore;
    readonly Reconciler _reconciler;
    readonly Poller _poller;
    readonly RepoLocator _repos;
    readonly AgentCoordinator _agents;
    readonly HookDispatcher _hooks;
    readonly ToastPresenter _toasts = new();
    readonly IClaudeLauncher _launcher;
    readonly CancellationTokenSource _cts = new();
    readonly object _saveGate = new();
    readonly System.Collections.Concurrent.ConcurrentDictionary<string, DateTimeOffset> _announced = new();
    bool _claudeAvailable;

    public event Action? Changed;

    public AppController(ConfigStore config, StateStore stateStore)
    {
        _config = config;
        _stateStore = stateStore;
        var state = stateStore.Load();
        _reconciler = new Reconciler(state.Snapshot.ToDictionary(kv => kv.Key, kv => (IReadOnlyList<InboxItem>)kv.Value));

        var runner = new ProcessRunner();
        var ghSource = new GitHubSource(
            new GitHubClient(new HttpClient { Timeout = TimeSpan.FromSeconds(25) }, new GhTokenProvider(runner)),
            () => _config.Current.GitHub);
        var adoClient = new AdoClient(new HttpClient { Timeout = TimeSpan.FromSeconds(25) }, new AzTokenProvider(runner));
        var directory = new AdoDirectory(adoClient);
        var catalog = new CompositeCatalog(
            new StaticCatalog(() => _config.Current.GitHub.Enabled ? [ghSource] : []),
            new AdoSourceCatalog(directory, () => _config.Current.Ado,
                org => new AdoOrgSource(org, adoClient, directory, () => _config.Current.Ado)));
        _poller = new Poller(catalog, _reconciler, TimeSpan.FromSeconds(30));
        _poller.Polled += HandleDiff;

        _repos = new RepoLocator(() => _config.Current.RepoRoots);
        _claudeAvailable = CommandResolver.Find("claude") is not null;
        var deps = new AgentDeps(_repos, new WorktreeManager(runner, AppPaths.Worktrees), new ClaudeRunner(runner),
            new SkillLocator(SkillLocator.DefaultClaudeHome), () => _claudeAvailable);
        _agents = new AgentCoordinator(deps, () => _config.Current, AppPaths.Scratch, restored: state.AgentRuns);
        foreach (var r in state.AgentRuns)
            if (r.FinishedAt is { } f) _announced[r.Key] = f; // don't re-announce runs finished before a restart
        _agents.RunChanged += OnRunChanged;
        _agents.RunRemoved += _ => { Save(); Changed?.Invoke(); };
        _hooks = new HookDispatcher(runner, () => _config.Current);
        _launcher = new ClaudeLauncher(runner);
    }

    public DateTimeOffset? LastPolledAt => _poller.LastPolledAt;
    public string ConfigPath => _config.Path;

    public void Start()
    {
        HandleDiff(_reconciler.RetireWhere(IsDisabledSource));
        _ = _poller.RunAsync(() => TimeSpan.FromSeconds(_config.Current.PollSeconds), _cts.Token);
    }

    public async Task RefreshAsync()
    {
        try { await _poller.PollOnceAsync(_cts.Token); }
        catch (Exception ex) when (ex is not OperationCanceledException) { Log.Error("manual refresh failed", ex); }
    }

    public void ReloadConfig()
    {
        _config.Load();
        _claudeAvailable = CommandResolver.Find("claude") is not null;
        HandleDiff(_reconciler.RetireWhere(IsDisabledSource));
        Changed?.Invoke();
        _ = RefreshAsync();
    }

    bool IsDisabledSource(string name)
    {
        var c = _config.Current;
        if (name == "GitHub") return !c.GitHub.Enabled;
        if (name == "ADO" || name.StartsWith("ADO:", StringComparison.Ordinal))
            return !c.Ado.Enabled ||
                   (name.StartsWith("ADO:", StringComparison.Ordinal) && c.Ado.ExcludeOrgs.Contains(name[4..], StringComparer.OrdinalIgnoreCase));
        return false;
    }

    void HandleDiff(InboxDiff diff)
    {
        var cfg = _config.Current;
        foreach (var t in NotificationPolicy.Plan(diff, WorkHours.IsWithin(cfg.WorkHours, DateTime.Now))) _toasts.Apply(t);
        foreach (var i in diff.InitialLoad) { _agents.OnItemAdded(i); MaybeAutoRun(i, cfg); }
        foreach (var i in diff.Added) { _agents.OnItemAdded(i); _ = _hooks.DispatchAsync(HookEvent.ItemAdded, i); MaybeAutoRun(i, cfg); }
        foreach (var c in diff.Changed) { _agents.OnItemChanged(c); _ = _hooks.DispatchAsync(HookEvent.ItemChanged, c.New); }
        foreach (var r in diff.Removed) { _agents.OnItemRemoved(r); _ = _hooks.DispatchAsync(HookEvent.ItemRemoved, r); }
        _ = SweepAsync();
        Save();
        Changed?.Invoke();
    }

    void MaybeAutoRun(InboxItem item, AppConfig cfg)
    {
        var d = RulesEngine.Decide(item, cfg);
        if (d.Mode == AgentMode.Auto) _agents.TryStart(item, d, manual: false);
    }

    async Task SweepAsync()
    {
        try { await _agents.SweepAsync(_cts.Token); }
        catch (Exception ex) when (ex is not OperationCanceledException) { Log.Error("agent sweep failed", ex); }
    }

    void OnRunChanged(AgentRun run)
    {
        // RunChanged also fires for later edits (opened, item removed); announce each finished run once.
        if (run.State is AgentState.Ready or AgentState.Failed && run.FinishedAt is { } finished &&
            _announced.GetValueOrDefault(run.Key) != finished && Find(run.Key) is { } item)
        {
            _announced[run.Key] = finished;
            var label = InboxPresenter.LabelFor(run.Profile);
            if (WorkHours.IsWithin(_config.Current.WorkHours, DateTime.Now))
                _toasts.Apply(new ToastRequest(ToastAction.Show, ItemTag.ForAgent(run.Key),
                    $"{label} {(run.State == AgentState.Ready ? "ready" : "failed")}: {item.Repo}",
                    $"{item.Title}\n{run.Summary ?? run.Error}", item.Url));
            _ = _hooks.DispatchAsync(HookEvent.AgentFinished, item, run);
        }
        Save();
        Changed?.Invoke();
    }

    InboxItem? Find(string key) => _reconciler.Entries.FirstOrDefault(e => e.Item.Key == key)?.Item;

    public IReadOnlyList<InboxSection> BuildSections() =>
        InboxPresenter.Build(_reconciler.Entries, _agents.Get, i => RulesEngine.Decide(i, _config.Current), _agents.WhyCannotRun,
            DateTimeOffset.Now);

    public IReadOnlyList<string> Problems()
    {
        var list = _reconciler.Statuses.Where(s => !s.Healthy).Select(s => $"{s.Name}: {s.Problem}").ToList();
        if (_config.Error is { } e) list.Insert(0, e);
        return list;
    }

    public (int Count, bool Unhealthy) TrayState() =>
        (_reconciler.Entries.Count, _config.Error is not null || _reconciler.Statuses.Any(s => !s.Healthy));

    public void RunAgent(string key)
    {
        if (Find(key) is not { } item) return;
        _agents.TryStart(item, RulesEngine.Decide(item, _config.Current), manual: true);
    }

    public void OpenInClaude(string key)
    {
        if (_agents.Get(key) is not { SessionId: { } sid, WorktreePath: { } wt }) return;
        try
        {
            _launcher.Resume(wt, sid);
            _agents.MarkOpened(key);
        }
        catch (Exception ex)
        {
            Log.Error($"could not open claude for {key}", ex);
        }
    }

    public void OpenUrl(string target)
    {
        try { Process.Start(new ProcessStartInfo(target) { UseShellExecute = true })?.Dispose(); }
        catch (Exception ex) { Log.Error($"could not open {target}", ex); }
    }

    void Save()
    {
        lock (_saveGate)
        {
            try
            {
                _stateStore.Save(new AppState { Snapshot = _reconciler.Snapshot(), AgentRuns = _agents.Runs.Values.ToList() });
            }
            catch (Exception ex) when (ex is IOException or UnauthorizedAccessException)
            {
                Log.Error("could not save state", ex);
            }
        }
    }

    public void Dispose()
    {
        _cts.Cancel();
        _agents.Dispose();
        Save();
    }
}
```

```csharp
using System.Windows;
using System.Windows.Media;
using System.Windows.Threading;
using GhNotify.Core;
using H.NotifyIcon;
using Microsoft.Toolkit.Uwp.Notifications;

namespace GhNotify.App;

public partial class App : Application
{
    static readonly Brush Idle = new SolidColorBrush(Color.FromRgb(0x6B, 0x6B, 0x6B));
    static readonly Brush Busy = new SolidColorBrush(Color.FromRgb(0x2F, 0x81, 0xF7));
    static readonly Brush Warn = new SolidColorBrush(Color.FromRgb(0xF0, 0xA0, 0x40));

    Mutex? _mutex;
    TaskbarIcon? _tray;
    PopupWindow? _popup;
    AppController? _controller;
    FileSystemWatcher? _watcher;
    DispatcherTimer? _debounce;

    protected override void OnStartup(StartupEventArgs e)
    {
        base.OnStartup(e);
        _mutex = new Mutex(true, @"Local\GhNotify.SingleInstance", out var first);
        if (!first)
        {
            Shutdown();
            return;
        }

        Log.Configure(AppPaths.Logs);
        DispatcherUnhandledException += (_, a) => { Log.Error("unhandled UI exception", a.Exception); a.Handled = true; };
        AppDomain.CurrentDomain.UnhandledException += (_, a) => Log.Error("unhandled exception", a.ExceptionObject as Exception);
        TaskScheduler.UnobservedTaskException += (_, a) => { Log.Error("unobserved task exception", a.Exception); a.SetObserved(); };

        var config = new ConfigStore(AppPaths.ConfigFile);
        config.Load();
        _controller = new AppController(config, new StateStore(AppPaths.StateFile));
        _popup = new PopupWindow(_controller);

        _tray = new TaskbarIcon { ToolTipText = "gh_notify" };
        _tray.TrayLeftMouseUp += (_, _) => TogglePopup();
        UpdateTray();
        _tray.ForceCreate();

        _controller.Changed += () => Dispatcher.InvokeAsync(() =>
        {
            UpdateTray();
            if (_popup.IsVisible) _popup.Render();
        });
        ToastNotificationManagerCompat.OnActivated += a => Dispatcher.InvokeAsync(() =>
        {
            var args = ToastArguments.Parse(a.Argument);
            if (args.TryGetValue("url", out var url)) _controller.OpenUrl(url);
            else _popup.ShowNearTray();
        });

        WatchConfig();
        _controller.Start();
        Log.Info("gh_notify started");
    }

    void TogglePopup()
    {
        if (_popup!.IsVisible) _popup.Hide();
        else _popup.ShowNearTray();
    }

    void UpdateTray()
    {
        var (count, unhealthy) = _controller!.TrayState();
        _tray!.IconSource = new GeneratedIconSource
        {
            Text = count > 99 ? "99+" : count.ToString(),
            Foreground = Brushes.White,
            Background = unhealthy ? Warn : count == 0 ? Idle : Busy,
            FontSize = count > 9 ? 40 : 52,
        };
        _tray.ToolTipText = unhealthy
            ? $"gh_notify — {count} waiting (a source needs attention)"
            : $"gh_notify — {count} waiting";
    }

    void WatchConfig()
    {
        _debounce = new DispatcherTimer { Interval = TimeSpan.FromMilliseconds(400) };
        _debounce.Tick += (_, _) =>
        {
            _debounce.Stop();
            _controller!.ReloadConfig();
        };
        Directory.CreateDirectory(AppPaths.ConfigDir);
        _watcher = new FileSystemWatcher(AppPaths.ConfigDir, "config.json")
        {
            NotifyFilter = NotifyFilters.LastWrite | NotifyFilters.FileName | NotifyFilters.Size,
            EnableRaisingEvents = true,
        };
        FileSystemEventHandler restart = (_, _) => Dispatcher.InvokeAsync(() => { _debounce.Stop(); _debounce.Start(); });
        _watcher.Changed += restart;
        _watcher.Created += restart;
        _watcher.Renamed += (s, a) => restart(s, a);
    }

    protected override void OnExit(ExitEventArgs e)
    {
        _watcher?.Dispose();
        _controller?.Dispose();
        _tray?.Dispose();
        _mutex?.Dispose();
        base.OnExit(e);
    }
}
```

````markdown
# gh_notify

A small Windows tray app that shows everything on GitHub and Azure DevOps waiting on you:

- review requests
- pipeline and deployment approvals
- your PRs with failing CI
- your PRs that need a response

It toasts new items during work hours. When something is merged, approved or
voted on, it disappears from the inbox, and its toast is removed from Action
Center.

It can also pre-run Claude Code agents, so a review is already done by the time you open it.

## Requirements

- Windows 10/11, .NET 10 SDK
- `gh` logged in (`gh auth login`). Used for GitHub.
- `az` logged in (`az login`). Used for Azure DevOps. One login covers every org.
- Optional: `claude` (Claude Code) on PATH, for agents.

## Run

```
dotnet run --project src/GhNotify.App
```
or publish it with `dotnet publish src/GhNotify.App -c Release -o publish` and run `publish\GhNotify.exe`.
Use the popup's **⋯ → Start with Windows** to launch it at login.

## Agents and skills

The app ships **no skills**: bring your own. The built-in profiles call `/peer-review` (for review requests) and
`/pr-shepherd` (for your red PRs). A skill counts as installed if its `SKILL.md` is in one of these places:

- `~/.claude/skills/<name>/`
- the repo's `.claude/skills/<name>/`
- an installed Claude Code plugin

If a skill is missing, the row's button is disabled and its tooltip says why.

Agents run unattended in a throwaway git worktree of your local clone, found under `repoRoots`.
They are told not to post, push or comment, and a deny list blocks the usual commands for that.
When a run finishes, the row shows **✓ Ready** and a toast appears.
**Open in Claude** resumes that exact session in Windows Terminal, so you can approve what gets posted.

## Hooks

Each hook gets the item as JSON on stdin, plus these environment variables:
`GHN_EVENT`, `GHN_KEY`, `GHN_URL`, `GHN_KIND`, `GHN_REPO`.
The events are `ItemAdded`, `ItemRemoved`, `ItemChanged` and `AgentFinished`.

## Files

- Config: `%APPDATA%\GhNotify\config.json`
- State: `%LOCALAPPDATA%\GhNotify\state.json`
- Logs: `%LOCALAPPDATA%\GhNotify\logs\`
- Agent worktrees: `%LOCALAPPDATA%\GhNotify\worktrees\`
````
