# gh_notify v2.1 (macOS): task list

**Spec:** `docs/superpowers/specs/2026-10-16-gh-notify-v2.1-design.md`. It carries the design; this list only orders the
work. It is a short list, not a full-code plan (see the lean-process note). Branch: `feat/v2.1`.

**Constraints:**
- Windows behaviour is unchanged.
- Placeholder names only.
- Never run `test-install.ps1`, `Setup.exe` or `vpk pack` locally.
- Anything macOS-only (Swift, packing, Mac tests) is verified in CI on `macos-latest`. Windows can't run it.
- Gates: `dotnet build GhNotify.slnx -c Release -warnaserror`, `dotnet test`, `dotnet format --verify-no-changes`.

| # | Area | Files | Tests |
|---|---|---|---|
| 1 | **Core** | `HotkeyParser` (Cmd/Command/Option/Opt aliases; macOS `ToString`), `AppConfig` (platform default hotkey; `Display.Terminal = "terminal"`), `ConfigValidator` (terminal not empty), `[WindowsFact]`/`[WindowsTheory]` attributes in the test project, applied to the 11 Windows-only tests; OS-rooted sound paths in `ConfigValidatorTests` and `SettingsDraftTests` | Parser aliases and round trip; default hotkey per OS (inject `isMac`); validator; existing tests unchanged on Windows |
| 2 | **UI** | `AvaloniaSystemTheme` (in `GhNotify.UI/Platform`); `PopupWindow` placement top-right on macOS (inject the platform flag, keep the Windows path); tray template icon on macOS; Settings › Advanced `Terminal` field (macOS only) and the login-item "requires approval" hint; `docs/configuration.md` | Headless: placement math for both platforms; Advanced shows Terminal only when `IsMac`; local-choices round trip |
| 3 | **Platform.Mac (C#)** | `GhNotify.Platform.Mac.csproj`; `IMacShim` + `NativeShim` (`LibraryImport`, `ghn_version` check); `MacNotifier`, `MacHotkeyService` + `MacKeyCodes`, `MacStartupService`, `MacSoundService`, `MacShell` + `TerminalCommand` (quoting), `LoginShellPath`, `NoOp*` fallbacks; `tests/GhNotify.Platform.Mac.Tests` | Fake shim: click translation and replay, hotkey mapping and duplicate error, startup status mapping; quoting for every terminal mode (quote, space, `$`, `\`); PATH merge and timeout; keycode table. Shim-loading tests are macOS-only |
| 4 | **Swift shim** | `native/mac/GhNotifyMac.swift`, `native/mac/build.sh` (universal, `-target arm64-apple-macos13` + `x86_64`, `lipo`) | Built and loaded in CI by task 3's macOS-only tests |
| 5 | **Mac host** | `src/GhNotify.App.Mac`: `Program` (Velopack, `--version`, `--write-icns`, `--test-notification`, lock-file single instance), `MacPaths`, `Composition` (shim or no-op fallback; `LoginShellPath.Merge()` first), `StartupErrorWindow`, `Info.plist`; links `VelopackUpdateClient.cs` and `AppVersion.cs`; add to `GhNotify.slnx` | `MacPaths` env overrides and defaults (pure); instance lock (two locks on the same temp file) |
| 6 | **Pack, CI, release** | `build/pack-mac.sh`, `build/test-install-mac.sh`; `ci.yml` `mac` job and artifact; `release.yml` `pack-mac` job and the channel-crossing check; coverage excludes for the Mac projects | CI itself: the macOS job green, including install, upgrade and uninstall |
| 7 | **Tester round 2** | `build/mac-test.sh --round 2 <pkg>`, sample config, checklist, zip; `docs/macos-testing.md` Round 2 | Shellcheck-clean under bash 3.2 rules; dry run of the non-install parts in CI |
| 8 | **Docs** | `docs/install-macos.md`, `README.md`, `docs/development.md`, `docs/roadmap.md`, `docs/releases/v2.1.0.md` | Leak scan; links resolve |

Order: tasks 1 and 2 (verifiable on Windows), then 3 and 4, 5, 6 (iterate on CI until the macOS job is green), 7, 8.
Then one final review of the whole branch, and open the PR so the tester gets an artifact.
