# gh_notify v1.3.0

Clear work from the tray. The common "it's waiting on me" items can now be finished from the popup, not just seen there: merge a ready PR, re-run failed CI, approve several deployments at once, and do it all from the keyboard.

![The confirm panel for an approval](../images/approve.png)

## Highlights

- **Merge from the tray:** "Ready to merge" rows get **Merge…**. You choose merge, squash or rebase (only the methods the repo allows) and whether to delete the branch. The merge is pinned to the commit you saw, so a push in the meantime refuses it instead of merging something else. [Learn more](../actions.md#merge)
- **Re-run failed checks:** "CI failing" rows get **Re-run failed…**, which re-runs only the failed GitHub Actions jobs, or re-queues the failed build policies on Azure DevOps. [Learn more](../actions.md#re-run-failed)
- **Batch approvals:** with two or more approvals waiting, **Approve all…** and **Reject all…** handle them with one confirm. Each item is re-checked live, and you get a result for each one. [Learn more](../actions.md#batch-approvals)
- **Keyboard first:**
  - **Win+Shift+G** opens the popup from anywhere.
  - ↑/↓ moves between rows, Enter opens, Space expands.
  - A, R, M and C start approve, reject, merge and re-run.
  - `/` or Ctrl+F searches by repo, title, author or PR number.

  [Learn more](../actions.md#keyboard-shortcuts)

## New

- Settings → General: change or turn off the global hotkey. If another app already uses it, Settings says so.
- `actions.mergeMethod` sets your preferred merge method. It's used when the repo allows it.

## Changed

- Every action keeps the same safety rules as approvals:
  - a live re-check;
  - a plain statement of what will happen;
  - a Confirm button that stays disabled for 600 ms.

## Upgrade notes

Nothing to do. The two new config keys are optional:
- `hotkey` defaults to `Win+Shift+G`; `""` turns it off.
- `actions.mergeMethod` is unset by default. Unset, it picks squash, then merge, then rebase, whichever the repo allows first.
