# gh_notify v2.1.0

Clicking a "Pre-review ready" notification now takes you straight into that Claude session, so you can pick up a review
without going through the PR first.

## Highlights

- **Pick up a pre-review from its notification:** clicking "Pre-review ready" (or "Diagnose ready") resumes that run's Claude
  session in a terminal, like **Open in Claude** in the popup, instead of opening the PR. If the run failed or its worktree
  is gone, the click opens the PR as before. [Learn more](../workflows.md#built-in-profiles)

## New

- **About gh_notify** in the tray menu and the popup's ⋯ menu: the version, a link to the GitHub repo, and **Report an issue**, which opens a new issue with your version and OS filled in.
